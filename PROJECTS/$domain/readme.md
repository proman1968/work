# Раздел «Проекты» (`/PROJECTS`)

Домен верхнего уровня для управления проектами (`$project`).

В отличие от организаций (`/ORGANIZATIONS`, тип `$base`), в проектах (`$project`) нет иерархии подразделений (`$structure`) — рабочие места и роли участников (`#security.ROLES`) с доступом к данным (`LINKS`) настраиваются непосредственно в самом проекте. Каждый проект имеет собственное файловое пространство, чат, задачи `.task` и изолированную базу данных `PROJECTS/<Проект>/$project/#system/work.db`.
