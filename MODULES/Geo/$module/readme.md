# Модуль Geo — Геолокация, шейпы и карты (`$module`)

Модуль пространственных данных и интерактивных карт для WORK:

- **`Координаты` (`$struct`)** — широта (`lat`), долгота (`lon`), масштаб (`zoom`).
- **`Шейп` (`$struct`)** — геометрические контуры (`point`, `line`, `polygon`, `circle`, `geojson`, `radius`, `color`).
- **`Карта` (`$catalog` как миксин для оси `types`)** — добавляет любому подключённому классу (`Склады`, `Транспорт`, `Геоточки` и др.) поля `coords` и `shape`, а также вкладку **`Карта` (`form/map`)** с поддержкой OpenStreetMap, 2GIS, Яндекс и Google.
- **`Геоточки` (`$catalog`)** — готовый справочник точек интереса и геозон с `types: ['/MODULES/Geo/Карта']`.
