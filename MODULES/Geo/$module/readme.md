# Модуль Geo — Геолокация и координаты (`$module`)

Прикладной модуль геоданных, содержащий:

- **`Координаты` (`$struct`)** — составная структура геокоординат (`lat`, `lon`, `address`), подключаемая как поле или миксин (`types: ['/MODULES/Geo/Координаты']`) к справочникам и объектам учёта.
- **`Геоточки` (`$catalog`)** — справочник географических точек и адресов на карте.
