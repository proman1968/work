# MODULES — домен функциональных модулей (`$domain`)

Контейнер прикладных и системных модулей типа `$module` (`/MODULES/Register`, `/MODULES/Geo` и др.).

## Правила

1. Внутри `/MODULES` размещаются эталонные функциональные пакеты (`$module`).
2. Классы внутри `/MODULES/<Модуль>` задают базовые схемы (`FIELDS`, `POSTINGS`, `OVERLAY`, `SOURCE`), экранные представления (`handlers/pages/form/*`) и печатные шаблоны (`print/*.html`).
3. В организациях (`/ORGANIZATIONS/<Организация>/MODULES/<Модуль>`) одноимённые классы автоматически наследуют метаданные и формы от корневого модуля по оси `Ancestor`.
4. На каждом узле `$module` в дереве проводника доступен чек-бокс включения/блокировки модуля (`set_enabled`): в корне `/MODULES/<Модуль>` он блокирует модуль во всей системе, а внутри организации — только для этой организации.
