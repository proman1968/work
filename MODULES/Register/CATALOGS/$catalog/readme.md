# CATALOGS — справочники организации (`$catalog` и `$virtual`)

## 1. Что это

Корневой контейнер справочников учётного модуля (`CATALOGS` внутри `/MODULES/Register/CATALOGS` и в организациях `/ORGANIZATIONS/<Организация>/MODULES/Register/CATALOGS`).

## 2. Типы справочников

1. **Реальный справочник (`$catalog`):**
   - **Группа справочников** (у класса есть дочерние классы `$catalog`, например `Адресаты` → `Юридические лица`, `Физические лица`, `ИП`): собственных объектов не создаёт, но агрегирует объекты всех дочерних справочников и служит полиморфным типом ссылки.
   - **Лист справочника** (дочерних `$catalog` нет, например `Номенклатура`, `Склады и резервуары`, `Транспорт`): хранит объекты справочника с историей версий (`valid_from`).
   - Отдельный тип `$registry` не используется — везде применяется единый `$catalog`.

2. **Виртуальный справочник (`$virtual`, например `Клиенты`, `Поставщики`, `Сотрудники`, `Сотрудники/В отпуске`):**
   - Определяется метаданными `SOURCE: { registry, account, slot, mode }` и дополнительными полями расширения `OVERLAY`.
   - Режим отбора `mode`:
     - `'turnover'` — все объекты базового справочника, участвовавшие в оборотах счёта (`Клиенты` на сч. 62, `Поставщики` на сч. 60);
     - `'balance'` — объекты с ненулевым остатком на счёте на выбранную дату (`Сотрудники` на сч. Кадры, `В отпуске` на субсчёте Отпуск).
   - Поддерживаются вложенные виртуальные справочники (`CATALOGS/Сотрудники/В отпуске`), которые наследуют `SOURCE.registry`, `SOURCE.slot` и поля `OVERLAY` от родительского `$virtual`.

## 3. Работа с объектами (UI и ИИ-агент)

- **В проводнике ODA:** у `$catalog` вид по умолчанию — `form/objects` (список, карточка объекта с вложенными структурами `$struct`, табличными частями `table: true` и траекторией остатков по счетам); у `$virtual` — `form/virtual` (состав на дату и редактирование полей `OVERLAY`).
- **Инструменты ИИ-агента:**
  - `describe_class` — схема полей справочника (с учётом наследования `Types` → `Ancestor` → `Parent`), `SOURCE` и `OVERLAY`;
  - `find_objects` — поиск и фильтрация объектов `$catalog` (`search`, `where`, включая точечные пути структур) или получение состава `$virtual` на дату (`at`, `mode`).
