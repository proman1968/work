# Модуль Register — Учётная система (`$module`)

Эталонная учётная конфигурация WORK по модели ODANT:

- **`STRUCTS` (`$struct`)** — составные структуры реквизитов (`ФИО` со склонением по падежам, `Адрес`, `Паспорт`, `Банковский счёт`, `Единица измерения`), поддерживающие вложенность и признак табличной части `table: true`.
- **`CATALOGS` (`$catalog`, `$virtual`)** — реальные справочники (`Субъекты` → `Юр. лица`, `ИП`, `Физ. лица`; `Номенклатура`, `Склады`, `Партии`, `Договоры`, `Транспорт`, `Должности`, `Виды нормативов`) и виртуальные справочники (`Клиенты`, `Поставщики`, `Сотрудники` → `В отпуске`).
- **`OPERATIONS` (`$operation`)** — дерево хозяйственных, кадровых и складских операций с правилами двойной записи `POSTINGS` и печатными формами `print/*.html`.
- **`REGISTER` (`$register`, `$account`)** — единый журнал проводок и иерархический план счетов (`01`–`99`, включая `67` + служебные счета) с аналитиками и 4-шаговым интерфейсом отчётности ODANT (`sheet`, `analysis`, `turnovers`, `entry`).
