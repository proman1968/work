# Модуль Register — Учётная система (`$module`)

Эталонная учётная конфигурация WORK по модели ODANT:

- **`STRUCTS` (`$struct`)** — составные структуры реквизитов (`Адрес`, `Паспорт`, `Единица измерения`), поддерживающие вложенность и признак табличной части `table: true`.
- **`CATALOGS` (`$catalog`, `$virtual`)** — реальные справочники (`Адресаты` → `Юридические лица`, `Физические лица`, `ИП`; `Номенклатура`, `Склады и резервуары`, `Партии`, `Договоры`, `Транспорт`, `Виды нормативов`) и виртуальные справочники (`Клиенты`, `Поставщики`, `Сотрудники` → `В отпуске`).
- **`OPERATIONS` (`$operation`)** — дерево хозяйственных, кадровых и складских операций с правилами двойной записи `POSTINGS` и печатными формами `print/*.html`.
- **`REGISTER` (`$register`, `$account`)** — единый журнал проводок и иерархический план счетов с аналитиками и 4-шаговым интерфейсом отчётности ODANT (`sheet`, `analysis`, `turnovers`, `entry`).
