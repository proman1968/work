# $account — счёт плана счетов

## 1. Что это

Тип счёта (и субсчёта) единого журнала проводок (`REGISTER`). Наследный предок для всех узлов плана счетов: код счёта = `id` папки, название = `label` в `class.js`.

## 2. Зачем это нужно

Отделить **журнал** (`$register`) от конкретных **счетов** (`$account`). Каждый счёт — самостоятельный класс со своими аналитиками (`METADATA.FIELDS` с `analytic: true`) и правами доступа. При проведении операции запись попадает непосредственно в класс счёта Дебета и в класс счёта Кредита (явная двойная запись).

## 3. Как это работает

1. Объявление типа — в метапапке журнала: `REGISTER/$register/$folder/$class/$account/`.
2. Создать счёт: `create_class` у журнала (`REGISTER`) или родительского счёта, **`type: '$account'`**, `id` = код счёта (`41`, `50`, `62`, `01`), в `class.js` — обязательно `label` и `icon` (из реальных наборов ODA: `carbon:`, `icons:`, `bootstrap:` и т.д.).
3. Аналитики счёта задаются в `METADATA.FIELDS` как поля-ссылки:
   `{ id: 'counterparty', label: 'Контрагент', type: 'Link', catalog: '/MODULES/Register/CATALOGS/Клиенты', analytic: true, required: true }`.
   При наследовании в организации путь справочника автоматически разрешается внутри текущей `$base`.
4. Поля справочника-аналитики и поля его расширения `OVERLAY` автоматически доступны в отчётах как **субаналитики** (двухэтапный отбор и группировка).
5. Если у счёта есть субсчета, проводки выполняются по конечным субсчетам-листьям, а родительский счёт агрегирует их обороты и сальдо.

## 4. Экранные формы и инструменты

- `handlers/pages/form/postings` — единое представление счёта с полосой `oda-packets`:
  - `mode: 'card'` — карточка проводок счёта с сальдо после каждой записи (`db_card`);
  - `mode: 'analysis'` — Экран 2 ODANT: Анализ счёта в разрезе аналитик и субаналитик (`db_sheet`);
  - `mode: 'turnovers'` — Экран 3 ODANT: двухпанельные Обороты счёта по периодам и документам (`db_turnovers`);
  - `entryCard` — Экран 4 ODANT: сборная карточка проводки (`db_entry`).
- Для ИИ-агента: инструмент `report` (`path` = путь счёта, `kind: 'sheet' | 'turnovers' | 'card' | 'entry'`) и `describe_class`.
