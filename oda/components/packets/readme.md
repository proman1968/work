# `oda-packets`

## 1. Что это

Полоса выбора периода (date packets bar) — аналог `odant-packets` из odant, но только дата-часть: без `contextItem` и без `$item`. Генерирует дерево дат из диапазона `[start, end] и выбирает в нём период.

## 2. Зачем это нужно

Единый способ выбрать период в интерфейсе: год, квартал, месяц, произвольный отрезок или весь диапазон — без календарной сетки и без привязки к структуре данных. Наружу отдаёт нормализованный `period` в `YYYY-MM-DD`, который можно сразу передать в запрос или в фильтр.

Библиотека `oda/components` не зависит от ядра WORK: компонент ничего не знает о типах данных, `contextItem` и `$class`. Потребитель только задаёт границы и слушает `selection-changed`.

## 3. Как это работает

Свойства `start`/`end` (строго `YYYY-MM-DD`) и `mode` (`day | month | quarter | year`) задают покрытие и гранулярность. `$observers._rebuild` пересобирает дерево при изменении любого из трёх.

**Дерево строго по гранулярности** — в `month`/`day` кварталов нет, они существуют только в `quarter`-режиме:

| `mode` | Структура |
|---|---|
| `year` | годы |
| `quarter` | год → `[весь год, q1..q4]` |
| `month` | год → `[весь год, YYYY-MM]` |
| `day` | год → `[весь год, YYYY-MM]` → дни |

**Полоса** — `[Сейчас, ...годы, <, period, >, Все]`. Годы в полосе идут **по убыванию** (`2026, 2025, 2024`), стрелки `<`/`>` шагают `_leaves` **по возрастанию** — это осознанное различие раскладки и навигации, а не ошибка.

**Маска** — глоб-префикс единицы гранулярности плюс `*`: `2024-03*`, `2024-q3*`, `2024*`. Несколько единиц объединяются `|`. Каждый префикс — ключ в `_dayIndex`, поэтому в том числе и квартал (`2024-q3*`) однозначно резолвится в диапазон дней.

**Период** считается в двух режимах: одиночный выбор — через `_leafSpan(name, type)` с обрезкой по фактическому покрытию; мульти-выбор (Ctrl) — через индекс по префиксам масок. Пункт `period` хранит собственные `start`/`end`, стрелки `<`/`>` шагают от его краёв.

**Ключ выбора `value`** — обратный вход: потребитель отдаёт компоненту, какой период показать, и получает ключ текущего выбора, чтобы сохранить его у себя. Это единственный способ пережить перезапуск и пересборку диапазона. `mask` для этого не годится: у пункта «Сейчас» это маска с сегодняшней датой, и сохранённая маска завтра выбрала бы вчера. Поэтому у «Сейчас» ключ **относительный** — `'now'`, а не его маска.

| `value` | Что восстанавливается |
|---|---|
| не задан (`undefined` или `''`) | ничего → «Все» (прежнее поведение) |
| `'now'` | «Сейчас» — всегда текущий день, а не дата из хранилища |
| `'*'` | «Все» |
| `'2024-03*'`, `'2024-03*\|2024-11*'` | единица гранулярности либо мульти-выбор |
| `'period:2024-03-05:2024-05-20'` | произвольный отрезок; границы обрезаются по покрытию |

Ключ не найден или его узел отключён («Сейчас» вне диапазона) — откат на «Все». При неверных `start`/`end` `value` **не** сбрасывается: это намерение потребителя, и невалидный диапазон не должен затирать ему сохранённый выбор.

У `value` нет `$def` — намеренно. Значение пропса по умолчанию публикуется наружу событием `value-changed` (его шлёт `notify` и для `$def`), и пустая строка записалась бы в потребителя раньше, чем придёт его собственный ключ: тот, кто отдал бы `'now'`, получил бы обратно `''`. До первой сборки `value` — `undefined`, что `_itemsByKey` трактует как «выбор не задан».

**`selection-changed` приходит дважды за одну смену выбора**: сначала как авто-событие пропа `selection` (detail — массив выбранных единиц, поля `period` нет), затем явно из `_applySelection` (detail — `{selected, selection, mask, period}`). Потребитель, читающий `e.detail.value.period`, обязан отсечь первый: иначе он среагирует на изменение без периода и, например, перезапросит данные без границ. Достаточно проверки `Array.isArray(e.detail.value)`.

**Подписи без таймзонного сдвига.** Границы, `period` и единицы гранулярности считаются ручным разбором `YYYY-MM-DD` — `new Date('2024-11-01')` парсится как UTC и в `America/*` уезжает на предыдущий месяц. Подписи и служебные строки на русском, локаль зафиксирована константой `LOCALE = 'ru-RU'`. При много годовом диапазоне в подпись месяца и дня добавляется год, иначе шесть одинаковых «ноябрь» на 2020–2025 неразличимы.

**Диалог произвольного периода** вызывается как `ODA.showDialog(input, { TITLE: { label: 'Период' } })`. `OK` и `CANCEL` не передаются — остаются стандартные подписи и оформление `oda-popover` («OK» с `icons:check`, «Отмена» с `icons:close`). Передача своих объектов `OK`/`CANCEL` заменила бы их целиком и убрала иконки с цветовым режимом.

**Диапазон ограничен** ~12 годами (`guard = 366 * 12`). Усечение не молчаливое: `error` содержит фактически покрытый диапазон.

**Поддеревья** (`<`, `period`, `>`, `Все`) помечены `_isRight` — это признак раскладки в полосе, а не признак «шагать стрелками». Отметка `selected` сбрасывается рекурсивно по всему дереву, иначе вложенный месяц или день остаётся подсвеченным в выпадающем меню.

**Меню выбора дня.** В `day`-режиме год открывает не `oda-menu-list`, а `oda-packets-months` — самостоятельный список с копией контракта `oda-menu-list` (без `extends`: ODA склеивает шаблоны родителя и потомка, и список рисовался бы дважды). Выбор месяца не закрывает окно: компонент сам вызывает `ODA.showMenu` с днями месяца и якорем `{target, x, y}`, где `target` — элемент внутри окна месяцев (по нему `ODA.showPopover` не гасит верхний уровень стека), а `x`/`y` — правый край и верх списка месяцев (по ним `oda-popover.layout` ставит окно). Выбранный день закрывает оба окна и возвращает имя дня, поэтому хост получает из одного `await` либо месяц, либо день. Пункт без дней («весь год») выбирается сразу. Escape закрывает окно дней, повторный — окно месяцев; клик по другому месяцу закрывает окно дней и открывает новое; клик вне закрывает оба, выбор не меняется.

**Список окна передаётся всегда явно.** `ODA.showMenu` без `params.menu` берёт `ODA.menuTag`, а приложение этот тег подменяет — в WORK это `item-menu`, контекстное меню (tools и дерево handlers по `$item`), которое `items` не рисует. Такое окно открывается пустым, высотой 0, и тихо, без ошибки в консоли. Поэтому обе точки вызова — `_onOpenMenu` (единицы гранулярности и окно месяцев) и `pick` в `oda-packets-months` (окно дней) — собирают меню сами: `menu: ODA.createComponent('oda-menu-list' | 'oda-packets-months', …)`. Это же условие независимости библиотеки от приложения; `imports` главного компонента тянет `oda-menu-list` явно (`/oda//menu-list.js`), чтобы тег был определён к моменту вызова. Оболочка окна (`ODA.popoverTag`) остаётся под контролем приложения — список от неё не зависит.

### Контракт для ИИ-агентов

- Тег `oda-packets`; свойства `start`, `end`, `mode`, `items`, `selection`, `selected`, `mask`, `period`, `value`.
- `start`/`end`/`period.start`/`period.end` — всегда `YYYY-MM-DD`, границы включительные, `start ≤ end` нормализуется автоматически.
- `mode` — гранулярность дерева, влияет на форму `mask` и на шаг стрелок.
- `mask` — строка-глоб: `YYYY*` | `YYYY-qN*` | `YYYY-MM*` | `YYYY-MM-DD*`, объединение через `|`. `period` — точные границы в днях, он надёжнее `mask` для выборок.
- `selected` — первый элемент `selection` (объект); `selection` — массив выбранных единиц; `selected == null`, если ничего не выбрано.
- `value` — ключ выбора: вход и выход одновременно (см. §3). Для хранения между сессиями — только он, а не `mask` и не `period`.
- Событие `selection-changed` с `{selected, selection, mask, period}`; шлётся и при пересборке по смене `start`/`end`/`mode` — потребитель узнаёт об изменении периода всегда. Пересборка **не** сбрасывает выбор на «Все»: он восстанавливается из `value`. На одну смену выбора событие приходит дважды (авто-событие пропа `selection` + явное) — см. §3.
- Пример: `p.start = '2024-01-01'; p.end = '2024-12-31'; p.mode = 'quarter';` → `period === {start: '2024-01-01', end: '2024-12-31'}` после первого кадра; выбор `2024-q3` → `mask === '2024-q3*'`, `period === {start: '2024-07-01', end: '2024-09-30'}`, `value === '2024-q3*'`.

## 4. Из чего это состоит

- `packets.js` — `oda-packets` (корневой), `oda-packets-row` (левая/правая части полосы), `oda-packets-item` + наследники `now-selector`, `selector`, `period-selector`, `left-arrow`, `right-arrow`, `oda-packets-months` (список месяцев окна выбора дня, без `extends`, копия контракта `oda-menu-list`), `oda-packets-period-input` (диалог произвольного периода)
- `index.html` — демо

## 5. В каком это состоянии

✅ работает. Логика дат покрыта тестом `tests/packets.test.js` (46 проверок, `npm test`): квартальный период, отсутствие кварталов в `month`/`day`, TZ-независимость подписей, шаг стрелок от кастомного периода, компактность маски в `day`-режиме, усечение диапазона, сброс отметки в дереве, восстановление подписи `period`, русские подписи, диалог периода (без своих `OK`/`CANCEL`, отмена не меняет выбор), меню выбора дня (в `day`-режиме окно месяцев своё и не закрывается, дни приходят в пункте, отметки месяца и дня берутся из выбранного дня, «весь год» выбирается сразу, в `month`-режиме список обычный), независимость списка окна от `ODA.menuTag` (окно дней и список единиц — свои `oda-menu-list` при подменённом теге, месяц без дней закрывает окно без создания списка, отмена окна дней ничего не гасит), ключ `value` (относительный `'now'`, маски, мульти-выбор, произвольный период с обрезкой, откат на «Все» при неизвестном ключе, сохранение выбора при пересборке, неприкосновенность ключа при неверных границах).

Первый потребитель — вид `form/objects`: границы полосы из `logs({mode: 'dates'})`, период (`mode="day"`) уходит в `index` как `from`/`to`, ключ хранится в виде с `$save` под ключом точки.

Рендеринг и жесты проверяются демо `index.html`; UI-стенд `npm run test:ui` компонент не покрывает. Подменённый приложением `ODA.menuTag` демо не воспроизводит (оно не грузит `/sources/client.js`) — воспроизведение живёт в `tests/packets.test.js`.

Известные ограничения:
- 🔧 компонент не локализован: подписи и служебные строки всегда русские, локаль `ru-RU` жёстко задана.
- 🔧 полоса идёт по убыванию лет, стрелки — по возрастанию (различие намеренное, см. §3).
- 🔧 в `day`-режиме маска произвольного периода собирается по месяцам, а не по дням — иначе она разрастается до сотен префиксов; точность обеспечивает `period`.
- 🔧 окно дней открывается строго справа от списка месяцев; если справа не хватает места, `oda-popover.layout` подтягивает его в экран, и окно может перекрыть список месяцев.
