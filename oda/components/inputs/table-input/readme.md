# `oda-table-input`

## 1. Что это

Поле-таблица: массив строк в `oda-table` с правкой ячеек.

## 2. Зачем это нужно

Табличные части документов (товары, позиции).

## 3. Как это работает

Колонки — `field.columns` `{id, label, type, options, calc, total}`; `calc` — выражение от полей строки (колонка только для чтения), `total` — итог в заголовке; кнопки: добавить, дублировать, удалить строку. Пустое `value` (`undefined`) — пустая таблица, «Добавить строку» создаёт массив.

Данные `value` таблица не мутирует: `oda-table` получает «линзу» над каждой строкой — поля колонок читаются и пишутся сквозь неё в исходную строку, а вычисляемые колонки (`calc`) считаются на лету и в `value` не попадают. `@value-changed.stop` на `oda-table` оставлен намеренно: `value-changed` контролов ячеек всплывает и без остановки был бы принят `oda-form` за значение всей таблицы.

### Контракт для ИИ-агентов

- Тег: `oda-table-input`; импорт: `/oda/components/inputs/table-input/table-input.js` (или `oda//table-input`).
- Базовые свойства `oda-input`: `value`, `field`, `readonly`, `disabled`, `required`, `placeholder`, `borderless`, `dense`; методы `validate()`, `focus()`; геттеры `errors`, `isValid`. Изменение значения — событие `value-changed` (двусторонняя привязка `::value`).
- `value`: Array строк.
- Пример:

```html
<oda-table-input :field="{label: 'Товары', columns}"></oda-table-input>
```

## 4. Из чего это состоит

- `table-input.js` — `oda-table-input` (наследник `oda-block-input`)
- `index.html` — демо: с данными, пустой, только чтение, свёрнутый
