# oda/components/inputs — Контролы ввода

## 1. Что это

Строчные и блочные контролы ввода с единым контрактом (`oda-input`, `oda-block-input`).

## 2. Зачем это нужно

Группирует компоненты одного назначения; демо категории — `index.html` (все демо рядом).

## 3. Как это работает

Каждый компонент — папка `<имя>/<имя>.js` с `readme.md` и `index.html`.

## 4. Из чего это состоит

- `input/` — база `oda-input`, `oda-options-input
- `block/` — база блочных `oda-block-input`
- `text/` — текст, пароль, e-mail, url, телефон, поиск
- `numeric/` — число
- `date/` — дата и время
- `checkbox/` — флажок
- `toggle/` — переключатель
- `range/` — ползунок
- `color/` — цвет
- `rating/` — оценка
- `otp/` — одноразовый код
- `select/` — выбор из списка
- `radio/` — группа radio
- `segmented/` — сегменты
- `combobox/` — ввод с подсказками
- `tags/` — метки
- `file/` — файл
- `icon-picker/` — иконка
- `textarea/` — многострочный текст (блочный)
- `markdown-input/` — markdown (блочный)
- `code-input/` — код (блочный)
- `media/` — изображение, видео, аудио (блочный)
- `gallery/` — галерея (блочный)
- `files/` — файлы (блочный)
- `links/` — ссылки (блочный)
- `list/` — список строк (блочный)
- `table-input/` — таблица (блочный)
