# `oda-block-input`

## 1. Что это

База блочных контролов: строка-заголовок (подпись, выжимка значения, кнопки) и тело произвольной высоты.

## 2. Зачем это нужно

Многострочные и составные значения (текст, медиа, коллекции, таблица) показываются одинаково: в свёрнутом виде — строка с выжимкой, в развёрнутом — тело.

## 3. Как это работает

- Наследник дописывает `<div class="body">`, задаёт `get summary()` (выжимка) и `get tools()` — кнопки заголовка `{icon, title, action(e), disabled, edit}`; `edit: true` скрывает кнопку в режиме чтения.
- переключает только кнопка-стрелка; `collapsed` сворачивает тело, `noHeader` скрывает заголовок, `caption` — подпись (по умолчанию из поля).

### Контракт для ИИ-агентов

- Тег: `oda-block-input`; импорт: `/oda/components/inputs/block/block.js` (или `oda//block`).
- Базовые свойства `oda-input`: `value`, `field`, `readonly`, `disabled`, `required`, `placeholder`, `borderless`, `dense`; методы `validate()`, `focus()`; геттеры `errors`, `isValid`. Изменение значения — событие `value-changed` (двусторонняя привязка `::value`).
- Свойства: всё от `oda-input` + `collapsed`, `collapsible`, `noHeader`, `caption`.
- Пример:

```html
<oda-textarea-input field='{"label": "Описание"}'></oda-textarea-input>
```

## 4. Из чего это состоит
