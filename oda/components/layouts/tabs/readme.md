# `oda-tabs`

## 1. Что это

Полоса вкладок (без содержимого): прокрутка, клавиатура, закрытие, перетаскивание.

## 2. Зачем это нужно

Переключение между открытыми документами.

## 3. Как это работает

Вкладка — `{label, icon, close(), allowClose}`; текущая — `focusedIndex`.

### Контракт для ИИ-агентов

- Тег `oda-tabs`; свойства `items`, `focusedIndex`, `align`, `allowDrag`; событие `close`.

## 4. Из чего это состоит

- `tabs.js` — `oda-tabs`, `oda-tabs-tab`
- `index.html`

## 5. В каком это состоянии

🧪 прототип: потребителей нет.
