# `oda-property-grid`

## 1. Что это

Инспектор `$public`-свойств реактивного объекта — компактная `oda-form` с группами по `$cat` / `$category`.

## 2. Зачем это нужно

Настройка компонентов в стенде `oda-tester` и в конструкторе форм класса (`builder`).

## 3. Как это работает

- Поля строятся из дескрипторов свойств: `$list` → выбор, Boolean → флажок, Number → число, `icon` / `…Icon` → выбор иконки; свойство только с геттером — только чтение.
- Данные формы — сам объект: запись идёт через его сеттеры.

### Контракт для ИИ-агентов

- Тег `oda-property-grid`, импорт `/oda/components/structure/property-grid/property-grid.js`.
- Свойство: `inspected` — объект (ODA-компонент или Reactor).

## 4. Из чего это состоит

- `property-grid.js` — `oda-property-grid`
- `index.html` — инспектор кнопки

## 5. В каком это состоянии

✅ работает (демо, `builder`, `oda-tester`).

## 6. Дальнейшие планы
