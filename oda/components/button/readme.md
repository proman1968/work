# `oda-button`

## 1. Что это

Кнопка на `oda-icon`: иконка и подпись, переключатель, группа.

## 2. Зачем это нужно

Основная кнопка библиотеки.

## 3. Как это работает

- `allowToggle` — переключатель (`toggled`), `toggleGroup` — радиогруппа кнопок.
- `disabled` — неактивна; `iconPos` — положение иконки.

### Контракт для ИИ-агентов

- Тег `oda-button`, импорт `oda//button`; свойства `label`, `icon`, `iconPos`, `disabled`, `toggled`, `allowToggle`, `toggleGroup`, `colorMode` + свойства `oda-icon`.

## 4. Из чего это состоит

- `button.js`
- `index.html`

## 5. В каком это состоянии

✅ работает.
