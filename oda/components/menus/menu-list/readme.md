# `oda-menu-list`

## 1. Что это

Список пунктов для всплывающего окна (содержимое `ODA.showMenu`).

## 2. Зачем это нужно

Контекстные меню и выбор из списка без собственного позиционирования.

## 3. Как это работает

Пункт `{label, icon?, hint?, value?, disabled?, group?, execute?(item)}`; выбор вызывает `execute` и закрывает окно результатом `value ?? пункт`; текущий `value` отмечен.

### Контракт для ИИ-агентов

- Тег `oda-menu-list`; свойства `items`, `value`, `iconSize`.
- Пример: `const v = await ODA.showMenu({ items }, event)`.

## 4. Из чего это состоит

- `menu-list.js` — `oda-menu-list`
- `index.html` — демо
