# `oda-menu`

## 1. Что это

Контекстное меню на нативном popover: заголовок, пункты, подменю, позиционирование от якоря.

## 2. Зачем это нужно

Контекстные меню компонентов (`showContextMenu`).

## 3. Как это работает

Пункт `{label, icon, subIcon, group, items, execute}`; подменю — вложенные `items`.

### Контракт для ИИ-агентов

- Тег `oda-menu`; свойства `items`, `title`, `icon`, `anchor`, `focusedItem`, `itemTemplate`.

## 4. Из чего это состоит

- `menu.js` — `oda-menu`, `oda-menu-item`
- `index.html`

## 5. В каком это состоянии

✅ работает; 🔧 закрытое меню остаётся в DOM.

## 6. Дальнейшие планы

- Удаление из DOM после закрытия; перевод на `ODA.showMenu`.
