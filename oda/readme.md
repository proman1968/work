# ODA — визуальный фреймворк

## 1. Что это

Веб-фреймворк на Web Components и реактивной системе Reactor (`/sources/reactor.js` — общая с сервером). Компонент объявляется `ODA({ is, template, imports, extends, ...свойства, геттеры, методы })`.

## 2. Зачем это нужно

Один способ писать интерфейс WORK: декларативный шаблон с директивами, реактивные свойства и геттеры (кэш + автоматические зависимости), общая стилевая модель (`tools/styles`).

## 3. Как это работает

- **Свойства** (`reactor.js` `proto2props`): значение по умолчанию (`foo: 1`), тип (`foo: String`), дескриптор (`{ $def, $type, $attr, $public, $save, get, set }`), блоки `$public: {…}`, `'@категория': {…}`, `$pdp: {…}`. Геттеры кэшируются; зависимости собираются при чтении; запись сбрасывает зависимых и планирует рендер (≈16 мс).
- **Сброс вычисленного**: `this.invalidate('key', …)` / `Reactor.invalidate(obj, …)` — вместо правки `[R].cache`.
- **Отключение из DOM** (`~if`, `~is`, перенос слота): элемент отписывается от чужих данных (нет утечек), свои связи сохраняет; при возврате (`Reactor.reattach`) пересчитывает геттеры и рендерится.
- **Шаблон** (`core/vnode.js`, `core/directives.js`): `~if`, `~is`, `~for` (массив/объект/число; вложенный — `$for.$for`), `~show`, `~style`, `~class` (строка/массив/объект `{cls: true}`), `~text`, `~html`, `~props`; `:prop` (пусто — одноимённое), `::prop` (двусторонняя), `@event.stop.prevent.passive.capture`, `attr="{{expr}}"`, текст `{{expr}}`. Выражения — в контексте `$pdp` хоста; ошибка выражения — `console.warn` с тегом и текстом выражения.
- **Жизненный цикл**: `ready()` → `render()`; `attached()` / `detached()`; `$listeners` (`resize` — ResizeObserver); `$observers: { метод(a, b) }` — вызов при изменении `this.a`/`this.b` (все определены).
- **Импорты**: `imports: 'oda//button, ~/lib//tree'` (поиск `//` на сервере). Внутри модулей компонентов — абсолютные пути (`/oda/components/…`): относительные от URL с `//` не резолвятся.
- **Кэш модулей**: ETag/304 (сервер), правка на диске сбрасывает сборки слоёв (`sources/host/watch.js`).

## 4. Из чего это состоит

- `oda.js` — точка входа: Node-помощники (`host`, `$for`, `$pdp`, `render`), `ODA.LocalStorage`, уведомления.
- `core/` — `component.js` (реестр, жизненный цикл), `vnode.js` (шаблон, рендер), `directives.js`, `events.js` (алиасы `tap`…, жест `track`), `compiler.js`, `observers.js`, `shared.js`.
- `components/` — кнопки, иконки, деревья, таблицы, редакторы (markdown, код), поля ввода, раскладки.
- `tools/` — стили, иконки, jupyter, property-grid, tester.

## 5. В каком это состоянии

Работает. Тесты Reactor — `tests/reactor.test.js`; UI-тесты в браузере — `tests/ui` (`npm run test:ui`).
