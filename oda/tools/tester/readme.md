# oda/tools/tester — стенд компонентов

## 1. Что это

Стенд ручной проверки: компонент в центре, `oda-property-grid` справа, вкладка предпросмотра в рамке устройства.

## 2. Зачем это нужно

Проверка свойств компонента без написания страницы.

## 3. Как это работает

Страница с первым элементом `<oda-tester>` — `oda/oda.js` подключает стенд, компонент берётся из слота.

## 4. Из чего это состоит

- `tester.js` — `oda-tester`, `oda-tester-container`, `work-tester`
- `device-preview/` — `oda-device-preview` (рамки устройств `devices.json`, выбор — `ODA.showMenu`)
- `index.html` — пример

## 5. В каком это состоянии

✅ работает.

## 6. Дальнейшие планы

- Убрать из `oda/oda.js` знание о стенде (подключение по атрибуту).
