# oda/tools/jupyter — ноутбук

## 1. Что это

Редактор и исполнитель `.ipynb` (ячейки кода и markdown, выводы).

## 2. Зачем это нужно

Просмотр и правка ноутбуков в WORK (`$ipynb`).

## 3. Как это работает

Выбор файла ячейки — метод `selectFileUrl(e, cell)` (по умолчанию `ODA.showPrompt`); WORK переопределяет его в `item-jupyter`.

## 4. Из чего это состоит

- `jupyter.js` — `oda-jupyter` и вспомогательные теги
- `index.html`
