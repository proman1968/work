# oda/tools/jupyter-compare — сравнение ноутбуков

## 1. Что это

Два ноутбука рядом с синхронной прокруткой.

## 2. Зачем это нужно

Сравнение версий `.ipynb`.

## 3. Как это работает

Загрузка по URL, ячейки сопоставляются по id.

## 4. Из чего это состоит

- `jupyter-compare.js` — `oda-jupyter-compare`, `oda-jupyter-lite`, `oda-jupyter-lite-cell`
- `index.html`

## 5. В каком это состоянии

🧪 прототип: нет обработки ошибок загрузки.

## 6. Дальнейшие планы

- Обработка ошибок, подсветка различий.
