## В работе
- Лёгкое `oda-tree` без колонок; перевод колоночных потребителей на `oda-table`.
- Перевод страниц редактора класса на `item-form` (`lib/item-form`).

## Ключевые решения
- Описание поля — соглашение: `{id, type?, label?, description?, icon?, fields?, items|options?, required?, readonly?, control?, expression?}`; тип-путь класса — ссылка (только системная часть).
- Карта контролов подаётся формой/таблицей (`controls`), системная часть её переопределяет.
- Вложенные поля строятся только у отрисованных полей раскрытых блоков — самоссылки классов не зацикливают.
- У колонок таблицы варианты — `options` (`items` колонки — дочерние колонки).
- Нативные API вместо собственных (input types, datalist, field-sizing, details, popover, accent-color, Highlight).
- В plain-HTML слушать `click` и `-changed`, не `tap` (алиас только для шаблонов); id не должны совпадать с `window` (`open`, `confirm`).
