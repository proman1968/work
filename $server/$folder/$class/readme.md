# $server/$folder/$class/ — тип класс

Прототип всех типизированных класс. Класс `$class extends $folder` — папка с метапапкой и `class.js`.

## Структура

- `class.js` — конфигурация: `$public.form = 'chat'`
- `$class/` — тип «класс» (метаданные)
- `$device/` — тип «устройство»
- `$structure/` — тип «структура»
- [`ai/`](ai/readme.md) — способность ИИ класса (`~/ai`, one-shot `?prompt`)
- `handlers/` — специфичные для класса обработчики

## Методы `$class`

- `load()` — загрузка и merge `class.js` из цепочки наследования
- `import()` — импорт `class.js` как ES-модуля
- `save()` — сохранение `class.js` (только разница с точкой наследования)
- `logs()` — единая точка чтения логов (mode: folder/bodies/index/files/dates)
- `read_log_entry()` — одна запись лога по stub `.logs` или связанному `row.path`
- `append_log_includes()` — добавить пути в includes записи лога
- `save_message({ message, includes })` — чистая лог-запись (сообщение без файла)
- `read_secret()` / `save_secret()` — секреты модулей в `#secret/`

## Метапапка

Метапапка (имя на `$`) — основная рабочая область класса. Содержит `class.js`, пользовательские файлы и папки. Для элементов внутри метапапки: `$class == $owner`.

## Устройство класса

- Точка — папка + одна метапапка (`$тип`) с `class.js`. Тело точки живет в meta, `readme.md` точки — ее контракт.
- Свое закрывает наследованное (`~`). Нет своего файла при наличии наследованного — не ошибка, действует родительское.
- Файлы — только через `save_file` в точку. Классы — только через `create`: родитель + тип + id + `class.js` в fence.

## Детские типы

- Тип детей точки объявлен в ее meta (`$folder/$class/*`) и назван в ее собственном `readme` одной строкой. Нет объявления — спросить человека, не подставлять пустой `$`.

## Проверка

- Факт сверяется через API: путь есть, файл читается, устройство импортируется. Ожидания содержимого — только из `readme` точки.
