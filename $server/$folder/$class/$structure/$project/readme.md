# Проект ($project)

Узел проектной деятельности в разделе `/PROJECTS/<Проект>`. Наследует возможности точки коллаборации от `$structure` (руководитель `BOSS`, чат и лента событий, задачи `.task`, файлы, календарь, почта, мессенджеры) и изолированную базу данных `<Проект>/$project/#system/work.db`.

## Ключевые особенности `$project`

1. **Плоская ролевая структура без подразделений:**
   - В отличие от организации (`$base`), внутри `$project` **нет оргструктуры** (дочерние `$structure` не создаются).
   - Все рабочие места и роли участников проекта (`#security.ROLES` с назначением пользователей `USERS` / `GUESTS` и ссылками на классы `LINKS`) создаются непосредственно на самом узле `$project` (вкладка **«Штат»** `form/staff`) и сразу отображаются под проектом в дереве проводника.
2. **Собственная БД и модули:**
   - Внутри проекта могут подключаться прикладные и учётные модули (`MODULES/<Модуль>`), данные которых хранятся в изолированной БД проекта `PROJECTS/<Проект>/$project/#system/work.db`.
   - Рабочие места проекта (`LINKS`) могут ссылаться как на собственные классы модулей проекта (`/PROJECTS/<Проект>/MODULES/...`), так и на классы организаций (`/ORGANIZATIONS/<Орг>/MODULES/...`).
3. **Архивация и перенос:**
   - Проект поддерживает упаковку в `.zip` (`export_archive`) и развёртывание из архива в разделе `/PROJECTS` (`import_archive`).
