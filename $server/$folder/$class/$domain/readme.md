# $server/$folder/$class/$domain — тип домен

Домен (`$domain`) — контейнер верхнего уровня в `$server` (или раздел внутри `$base` / `$module`), в котором группируются другие структуры (организации `$base`, модули `$module`, разделы данных `$catalog`, `$struct`, `$operation`, `$register`).

Допустимые дочерние типы внутри конкретного домена объявляются в его метапапке `$domain/$folder/$class/*`.
