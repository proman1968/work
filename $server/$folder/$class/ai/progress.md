# Прогресс: $class/ai

## Последние изменения
- [12:55] Заголовки блоков по контракту имя+объект+state: `state` ставят все evidence-tools (`ok`/`нет`/`ошибка`/редирект), guided-редиректы больше не `error` (красный — только настоящим провалам), явный `readme.md` без файла — честное «нет» без наследованного слоя. Причина: редирект «это папка» красился красным, у части блоков не было state, read подсовывал чужой типизатор.

## В работе
- Матрица из разнородных задач для проверки универсальности (дерево, журнал, внешняя информация, действие с check).

## Ключевые решения
- Решение: blacklist = «не раскрывать», а не «не показывать»: тяжёлое видно первым уровнем. Причина: полная невидимость ломает легитимные вопросы управления системой.
- Решение: вид цели не тот ≠ ошибка: редирект несёт state без error. Причина: красный — только провалам; редирект не должен жечь errorStreak и пугать.
- Решение: нового tool нет — расширяем `map`/`ls` тремя списками. Причина: отдельный tool жрёт слот меню и ход, fallback мешает evidence; три секции видны меню без новых типов.
- Решение: ключ ветки агента и `body.mode` — одно имя `build`. Причина: движок читает `agent[mode]`.
- Решение: ошибка create не жжёт ход; activation без ok read не в меню. Причина: write фразой в отсутствующий путь ломал второй work.
- Решение: после принятой activation меню build = create. Причина: pick search/write вместо create в несуществующий путь.
- Решение: пакет агентов не знает прикладной каталог. Причина: `if (type === '$ai')` в work — не принцип create.
- Решение: инварианты формулируются универсально, без триггер-фраз задачи. Причина: правка под конкретный прогон ломает автономное развитие.
- Решение: провенанс ставит код агента, не текст инструкции. Причина: контент read/meta заполняет `exec`, модель заголовок дописать не может.

## Блокеры / Открытые вопросы
- Долг: `body.tz` нигде не записывается; пояс берётся из локали сервера. Нужна запись `body.tz` из геолокации сессии.
- Долг: `explore` слеп к обычным папкам (`oda/`, `sources/`) — видит только `$class`. Нужен file-discovery вне классов (ODA-фреймворк лежит в `oda/`, не в дереве классов).
- Долг механики: `check` не видит `html`/`image` (нет `[create]/[write]` маркера); `work.read` без заголовка провенанса.
