# Скан в WORK

1. **Сканер:** инструмент `svc_<сканер>_scan` (нет — сканер не зарегистрирован или нет доступа: навык printer-setup/lan-inventory у администратора). `svc_<сканер>_status` — готов ли (`Idle`), есть ли автоподатчик (`Feeder` в возможностях).
2. **Куда:** класс-точка (`to`), роль — та, в чью зону класть (`role`, обычно USER). Имя — по содержанию: `Счёт Ромашка 2026-09-29.pdf`.
3. **Сканирование:** `svc_<сканер>_scan to=<класс> role=<роль> filename=<имя> dpi=300 source=Platen|Feeder` — одна страница A4 за вызов (многостраничные — по одной; объединение — отдельной задачей). Подтверждается.
4. **Содержание:** `read` файла — текст (для PDF/изображений распознаётся при чтении). Пусто — плохое качество: предложи 600 dpi.
5. **Разложить** (по просьбе): объект данных (`import_objects` с `rows`) или поручение `send` с вложением ответственному.
6. Итог: путь файла, что распознано, куда отправлено.
