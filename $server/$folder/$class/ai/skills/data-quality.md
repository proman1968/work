# Качество данных

1. **Схема:** поля типа (`schema`, `METADATA.FIELDS`): обязательные, типы, ключевые (код, ИНН, email).
2. **Выборка:** `query type=<тип> limit=500 offset=0, 500, 1000…` страницами, пока ответ не короче `limit` (фильтры по периоду/точке). Объектов много — работай по частям и копи итоги по ходу.
3. **Проверки:**
   - пустые обязательные поля;
   - дубли по ключу и по нормализованному имени (регистр, пробелы, «ООО»/кавычки);
   - форматы: ИНН 10/12 цифр с контрольной суммой, КПП 9, email, телефон, даты в будущем/далёком прошлом;
   - выбросы в числах (отрицательные суммы, на порядок выше медианы).
4. **Отчёт:** `write_table` `Отчёты/качество-<тип>-<дата>.xlsx` — листы «Сводка», «Пустые», «Дубли», «Форматы», «Выбросы» (путь объекта, поле, значение, что не так, предложение).
5. **Исправления** — только по согласию пользователя и по одному типу проблем за раз (`edit` объекта или повторный `import_objects`); дубли не удаляй — пометь и предложи, какой оставить.
6. Итог: сколько объектов проверено, проблем по видам, путь отчёта.
