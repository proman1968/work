# Документ по шаблону

1. **Шаблон.** Найди в контракте места или `find name=*шаблон*` / папке `Шаблоны`. Метки в шаблоне — `{{поле}}`, вложенные `{{клиент.inn}}`. Прочитай шаблон (`read`), выпиши метки.
2. **Данные.** Объект WORK (`query type=data where=…`, `read` его пути) и/или данные пользователя. Сопоставь метки с полями; чего нет — спроси, не придумывай (реквизиты, суммы, даты).
3. **Расчёты** (итоги, НДС, прописью) — посчитай сам и передай готовыми значениями.
4. **Создание:** `render_doc template=<шаблон> path=<Документы/тип №номер от дата.docx> data={…}` (или `data_path` объекта). Ответ сообщит незаполненные поля — дополни и пересоздай.
5. **Проверка:** `read` результата — все метки заменены, числа и реквизиты совпадают с источником.
6. По просьбе — `send` документа на согласование (навык approval-flow) или контрагенту.
7. Итог: путь документа, источник данных, что проверить человеку.
