# Как записать навык

1. **Стоит ли.** Навык — повторяемая процедура с инструментами и проверками. Одноразовое, личные данные пользователя и факты (для них `memory`) навыком не делай. Похожий навык уже есть в списке — предложи дополнить его, а не создавать второй.
2. **Имя:** латиница, цифры, дефис (`weekly-sales-report`); имя существующего навыка перезапишет его.
3. **description** — одна фраза «когда применять»: ситуация и слова пользователя, по которым навык выбирают. Это единственное, что видно в списке.
4. **Тело** — шаги по порядку:
   - какие инструменты и с какими параметрами; пути и контракты места — по WORK-путям из реального выполнения, проверенным `ls/read`;
   - где остановиться и спросить человека, что подтверждается;
   - как проверить результат;
   - подводные камни, на которые наткнулся.
   Не копируй данные конкретного прогона (имена людей, суммы, id); секретов нет вообще.
5. **Область:** `scope: place` — этот класс и ниже (по умолчанию, безопасно); `scope: global` — вся система (с подтверждением; только если рецепт не завязан на конкретное место).
6. **Сохранение:** `save_skill name=… description=… content=… scope=…`; покажи пользователю итоговый текст и путь.
7. Если навыку нужен особый ресурс (`os_*`/`net_*` или песочница) — после сохранения добавь через `edit` во фронтматтер файла `requires: system` или `requires: sandbox`, чтобы навык не мешал тем, у кого этого нет.
