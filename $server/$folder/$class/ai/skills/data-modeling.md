# Проектирование модели данных и форм

1. **Выбор типа класса:**
   - `$catalog` — реальный справочник (контрагенты, номенклатура, сотрудники). Группы агрегируют потомков, объекты создаются **только в листьях**.
   - `$struct` — переиспользуемая составная структура полей (паспорт, адрес, строка документа). Если поле ссылается на `$struct` без `table: true` — это вложенный объект (`struct`), если с `table: true` — табличная часть (`table`).
   - `$virtual` — виртуальный справочник, отбирающий элементы из реального `$catalog` по обороту (`mode: 'turnover'`) или ненулевому остатку (`mode: 'balance'`) на счёте (`SOURCE: { registry, account, slot, mode }`) + собственные дополнительные поля (`METADATA.OVERLAY`).
2. **Уровень создания и наследование:**
   - В контексте организации работай в `/ORGANIZATIONS/<Орг>/MODULES/<Модуль>/...` (не меняй общий `/MODULES/...`).
   - Общие поля выноси в родительский класс (`Parent`) или миксин (`types` — 1-я ось наследования), а специфика вида задаётся в классе-листе (`update_class`).
3. **Канонические типы полей (`METADATA.FIELDS`):**
   - `string`, `text`, `number`, `money`, `integer`, `boolean`, `date`, `datetime`, `enum` (`values: [...]`), `file`, `link` (`target: '/...'`), `struct` (`struct: '/...'`), `table` (`struct: '/...'`, `table: true`).
   - Имена `id` — латиница в `snake_case`, подписи `label` — по-русски. Обязательность — `required: true`.
4. **12-колоночная раскладка карточки (`METADATA.LAYOUT`):**
   - После задания `FIELDS` настрой базовый `METADATA.LAYOUT` через `update_class` (если раскладка ещё не настроена):
     - заголовки разделов: `{ id: 'hdr_main', kind: 'header', label: 'Основные реквизиты', span: 12 }`;
     - короткие поля (`num`, `time`, `date`, `status`, `sum`, `amount`, `inn`, `phone`, `boolean`): `span: 4`;
     - названия и ссылки (`name`, `counterparty`, `warehouse`): `span: 6`;
     - длинные тексты (`comment`, `address`) и табличные части (`table: true`): `span: 12`.
5. **Проверка:**
   - Вызови `describe_class` и `inspect_class_tree` на созданном/обновлённом классе и убедись, что нет ошибок схемы, циклов структур и конфликтов наследования.
   - Оформи контракт места (`readme.md`): назначение класса, ключевые поля, правила заполнения.
