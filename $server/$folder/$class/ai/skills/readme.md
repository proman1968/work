# skills — рецепты ленты

## 1. Что это

Файлы навыка в пакете `ai/` (сосед [`agents/`](../agents/)). Навык — не дамп `ai.task`, а рецепт: когда цеплять, какие точки, какие слоты, какой `pipe` оркестратора.

Имя файла = `id` + `.js`. Формат: `export default { … }` (данные, не код).

Файлы грузит `$task` из пакета движка (`_aiPackage` → `skills/`, иначе meta `ai/skills`). На новой цели: `@id` или `when.need` + `phrases` (одно попадание — сразу, несколько — тихое меню `none`|`id`). Нет точки из `points` — навык не надевается. Надетый навык: `body.skill = { id, cursor, slots }`, ходы из `pipe[]` вместо меню оркестратора; `system`/`prompt`/`tools` шага уходят в движок.

## 2. Зачем это нужно

Зафиксировать удачный сценарий (те же точки, те же ходы, другие данные), чтобы следующий прогон не собирал ленту из общего меню.

## 3. Как это работает

Один объект на файл. Поля:

- `id`, `label`, `icon` — идентичность; `id` совпадает с именем файла
- `when` — вход: `need` (`side` / `facts`), `phrases[]` (подстроки постановки для предфильтра и строк тихого меню). Выбор — на новой цели (`none` | `id`), не каждый ход. Явный `@id` — тот же вход, без угадывания
- `points` — замороженные пути удачного прогона. Replay ходит сюда же. Нет точки — отказ, не искать замену по карте
- `slots` — только переменные данные (`from`: `user` / `activation`). Форма элемента, не список из ленты
- `defaults` — значения слотов, если пользователь не задал («любые»)
- `pipe[]` — ходы оркестратора, типы из уже существующих агентов. Новых типов нет

Элемент `pipe[]`:

- `type` — ключ pipe (`explore`, `work`, `check`, …)
- `system` / `prompt` — добавка к агенту на этом боксе, не замена `agents/*.js`
- `tools[]` — предпочтительный внутренний порядок. Движок пропускает уже успешный tool (activation — только `state=принято`); после ok create — `total`, не второй create

Не класть в навык: thinking, ложные question, тела create, `using_blocks`, агенты `freeze` и `review`. Пути рабочих точек — в `points`.

Новый файл появляется не правкой руками, а агентом [`freeze`](/$server/$folder/$class/ai/agents/freeze.js/~/handlers/pages/form/): после удачного прогона меню «запомни / навык / рецепт» или `@freeze`. Черновик собирает код из ленты (`pipe` агентных боксов, `points` осмотра, `defaults` из create). Человек правит id / label / цельные phrases и APPROVE. Пишет `id.js` в этот каталог; кэш `$task._skills` сбрасывается. Не затирает существующий файл без `overwrite: да`. Пример `register-accounts` — эталон, не дефолтный id.
