# Счета в журнале /REGISTER

1. `read /REGISTER` — контракт журнала; `ls /REGISTER` — какие счета уже есть (их не трогать).
2. `read /REGISTER/$register/$folder/$class/$account` — тип счёта `$account` (поля и правила class.js).
3. Состав счетов — из реплики пользователя; если не указан — типовой набор:
   41 Товары, 43 Готовая продукция, 50 Касса, 51 Расчётные счета, 60 Расчёты с поставщиками,
   62 Расчёты с покупателями, 66 Краткосрочные кредиты, 67 Долгосрочные кредиты,
   68 Расчёты по налогам и сборам, 69 Расчёты по социальному страхованию, 70 Расчёты с персоналом,
   71 Расчёты с подотчётными лицами, 76 Расчёты с разными дебиторами и кредиторами, 90 Продажи,
   91 Прочие доходы и расходы, 99 Прибыли и убытки.
   Набор шире 5 счетов — покажи список и спроси подтверждение (ask_user) до создания.
4. Каждый счёт — `create_class` в `/REGISTER`: `id` = номер счёта, `type` = `$account`,
   `label` = «NN.00 Название»; иконка в class.js — из наборов carbon:, bootstrap:, iconoir: (например `carbon:receipt`).
   Независимые создания можно делать подряд в одном ходе.
5. Проверка: `ls /REGISTER` — все счета на месте; выборочно `read` одного счёта.
6. Итог: таблица «номер — название — путь».
