# Протокол встречи

1. **Источник:** текст пользователя, файл заметок/стенограммы (`read`), встреча `.ics` (`query type=ics`) — тема, время, участники.
2. **Разбор:** тема, дата, участники; обсуждённые вопросы (кратко); **решения**; **поручения** (что, кто, срок); открытые вопросы.
   Исполнитель или срок не ясен — не выдумывай: отметь «не назначено» и спроси пользователя.
3. **Документ:** `write` `Протоколы/ГГГГ-ММ-ДД тема.md` в точке встречи (или по контракту места):
   ```md
   # Протокол: <тема> — <дата>
   Участники: …
   ## Решения
   1. …
   ## Поручения
   | № | Что | Исполнитель | Срок |
   ## Открытые вопросы
   ```
4. **Рассылка** (после подтверждения пользователя): одна запись `send` с протоколом во вложении всем участникам; каждое поручение — отдельный `send kind=order` исполнителю со сроком (навык delegate-task).
5. Итог: путь протокола, id поручений, что осталось уточнить.
