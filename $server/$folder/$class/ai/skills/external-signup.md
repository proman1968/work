# Внешний сайт и подключение сервиса

**Показать страницу человеку:** инструмент `open_page { url, reason }` — страница откроется во встроенном предпросмотре WORK (если сайт запрещает фреймы — кнопка «Открыть в новой вкладке»). Каждое открытие человек подтверждает отдельно. Сам страницы не читаешь: регистрация, вход и кнопки на сайте — руками человека. Никогда не говори «не могу открыть» — предлагай `open_page`. Если человек просит выполнить действия на сайте за него и у него есть персональный компьютер — навык `computer` (браузер песочницы, только по явной просьбе).

**Подключить сервис (`provider: token`):** `connect_service` с `base_url` API плюс `signup` (страница регистрации) и `docs` (документация API) — они покажутся в карточке подключения рядом с полем токена. Токены и пароли в чате не спрашивай: человек вводит их сам в карточке.

**Типовой сценарий (видеосервис, любой API по токену):**
1. `open_page` на страницу регистрации (человек заводит аккаунт, забирает API-ключ).
2. `connect_service provider=token name=<имя> base_url=<API> signup=<та же страница> reason=…` — человек вставляет токен в карточку.
3. Дальше — `http_request с connection="<имя>"`. Изменение (не GET) — всегда с явным подтверждением и `reason` по-человечески.
