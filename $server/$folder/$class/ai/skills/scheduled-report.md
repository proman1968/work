# Работа по расписанию

1. **Сначала сделай один раз вручную** то, что будет повторяться (навык `summarize-feed`, `email-mailbox`, агент `analyst`…) и покажи результат: расписание ставят на проверенный рецепт.
2. **Параметры:** что делать (`prompt`), когда — одно из: `at=ЧЧ:ММ` + `days` (1 — пн … 7 — вс; без `days` — ежедневно), `every` минут (от 15), `once` — дата-время ISO. Время — в поясе задачи; сверься с блоком «Сейчас».
3. **Текст `prompt`** — самодостаточный, как поручение субагенту: точка/путь, период («за прошлую неделю»), куда сохранить (`Отчёты/…`), кому отправить через `send`. Запуск идёт новой репликой в ту же задачу от имени пользователя; действия с подтверждением будут ждать его.
4. **Создание:** `schedule action=create prompt=… at=… days=[…] label=<короткое название>` — человек подтверждает расписание. Запомни `id`.
5. **Проверка:** `schedule action=list` — следующий запуск совпадает с ожидаемым.
6. **Снять:** `schedule action=cancel id=<id>`; `action=list all=true` — все расписания пользователя.
7. Итог: что и когда будет запускаться, куда ляжет результат, как отменить. Расписание работает от имени владельца: отозванный доступ его выключает.
