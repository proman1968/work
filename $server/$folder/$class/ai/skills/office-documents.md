# Офисные документы

## Маршруты по форматам

1. **Читать:** `read` извлекает текст из PDF, DOC, DOCX, XLSX (и показывает класс/контракт). Старые `.doc`/`.xls` — только входной формат, новые документы создавай как `.docx`/`.xlsx`/`.pptx`.
2. **Встроенный офисный пакет WORK (`create_office_file`):** создаёт нативные `.pptx`, `.docx` и `.xlsx` файлы без внешних серверов — они сразу открываются и редактируются во встроенном браузерном редакторе WORK (`oda-office-editor`) и по протоколу WebDAV в настольном MS Office / LibreOffice / Р7:
   - **Презентации `.pptx`:** `create_office_file path=<файл.pptx> title=<название> slides=[{title, bullets:[…], text}]` или `export_presentation path=<файл.pptx или .pdf> title=<название> slides=[…]`.
   - **Документы Word `.docx`:** `create_office_file path=<файл.docx> title=<заголовок> html="<h1>…</h1><p>…</p><table>…</table>"`.
   - **Таблицы Excel `.xlsx`:** `create_office_file path=<файл.xlsx> sheets=[{name: "Отчёт", rows: [["Статья", "Сумма"], ["Выручка", 150000], ["Итого", "=SUM(B2:B2)"]]}]`.
3. **Таблицы и импорт:** `read_table path=<файл>` — листы и строки; `import_objects` — строки в объекты WORK (сначала `dry_run`, дубли не импортируй).
4. **Документы по шаблону:** `render_doc template=<шаблон> path=<результат> data={…}` (docx/md/html/txt, метки `{{поле}}`). Результат — того же расширения, что шаблон; ответ сообщает незаполненные поля — вернись к источникам и заполни, пустых меток в итоге быть не должно. Полный рецепт (поиск шаблона, сбор данных, проверка) — навык `doc-from-template`.
5. **Настоящий PDF:** из HTML через `export_pdf source=<файл.html> path=<файл.pdf>`.
6. **Презентации (PPTX и PDF 16:9):** `export_presentation path=<файл.pptx или файл.pdf> title=<название> slides=[{title, bullets:[…]}]` — слайды 16:9, титульный слайд с датой; или `source=<файл.md>` — слайды через строку `---` (первая строка слайда — заголовок, «- пункт» — список). Слайды ≤30, текст слайда ≤4000 символов.
7. **Сборка отчёта из источников одним действием:** найди шаблон (`find`), собери данные (`read`/`read_table`/`query`), заполни `render_doc`, сверь незаполненные поля; для офисных файлов — `create_office_file`, для PDF — `export_pdf`, для презентации — `export_presentation`. Цифры — только из источников; нет данных — «по запросу», не выдумывай.

## PDF: требования к HTML

- `@page { size: A4; margin: 12–15mm }`, системные шрифты (`Arial, Helvetica, sans-serif`), весь CSS — инлайн в `<style>`.
- Никаких внешних ресурсов (картинки — только встроенные, шрифты — только системные): при рендере сеть заблокирована.
- Кириллица — в UTF-8 с `<meta charset="utf-8">`.
- Проверка: `read` готового PDF (текст должен извлекаться, порядок разделов — как в HTML), размер — не байты.

## Правила документов для клиентов (КП, договоры, счета)

- Цены, реквизиты, сроки, подтверждённые возможности — только из источников (объект WORK, шаблон, слова пользователя). Нет данных — пиши «по запросу» / «уточнить», не выдумывай цифры.
- Итог пользователю: путь PDF, источник данных, что проверить человеку, отметь результат через `publish`.
