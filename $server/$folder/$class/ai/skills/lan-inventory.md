# Инвентаризация сети

1. `net_info` — интерфейсы и разрешённые подсети сервера (`#system/os.json subnets` или частные сети интерфейсов). Сети нет — сообщи и остановись.
2. `net_discover` — объявления устройств (mDNS, SSDP, WS-Discovery): принтеры, сканеры, МФУ, веб-интерфейсы. Не требует подтверждения.
3. `net_scan cidr=<подсеть> profile=printers|onec|servers` — только если объявлений мало и пользователь согласен; подтверждается каждый запуск.
4. `net_probe` по интересным хостам: IPP-принтер, eSCL-сканер; для 1С — полный URL публикации `http://<хост>/<база>/odata/standard.odata/` (имя базы спроси у пользователя или посмотри на веб-странице сервера 1С через `net_http`).
5. `net_candidates` — таблица находок: адрес, вид, подтверждение (`ipp`/`escl`/`odata` — проверено протоколом; `advertised`/`port-only` — предположение).
6. Регистрация (подтверждается): `net_register id=… name=<понятное имя> kind=… endpoint=…`. Для 1С — секрет доступа в `#secret` сервиса (`credentialFile`), без пароля в чате: попроси администратора положить его сам.
7. Доступ: назначить роли на класс сервиса (`assign path=/SERVICES/LAN/<имя> role=USER add=[…]`).
8. Проверка: `svc_<сервис>_status`.
9. Итог: таблица устройств (найдено / зарегистрировано / пропущено и почему), кому выдан доступ.
