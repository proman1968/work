# Сводка ленты

1. **Чья лента.** Точка (подразделение) — `logs path=<точка>`: целиком видна руководителю (BOSS/ADMIN), исполнитель видит только свои записи — так и скажи в сводке. Своя траектория — кабинет пользователя.
2. **Период.** Не задан — последние 7 дней. Сначала `logs dates:true`, затем `logs from=… to=…` (при «показаны последние N из M» — дроби по дням).
3. **Группировка записей:**
   - по участникам (`sender`, у представителей узлов — `actor`);
   - по видам (`[ext]`: документы, объекты, сообщения, задачи `.task`);
   - поручения — записи с `receivers` (кому, выполнено ли: есть ли ответная запись получателя).
4. **Содержание.** Для важных записей прочитай вложения (`read` пути из записи). По теме — `search` в точке.
5. **Сводка** (ответ, при просьбе — файл `Отчёты/сводка-ДАТА.md`):
   - Главное (3–5 пунктов);
   - Сделано (кто, что, ссылки);
   - В работе и открытые поручения (кому, с какого числа);
   - Риски и вопросы (просрочки, молчащие участники, ошибки);
   - Цифры (сколько записей, документов, объектов по видам).
6. Ничего не выдумывай: нет записей за период — так и напиши и назови последнюю дату с активностью.
