# Уведомление в Telegram

1. Инструменты `svc_Telegram_contacts` (адресная книга) и `svc_Telegram_send_message` (отправка). Нет их — сервис не настроен или нет доступа: скажи пользователю, что это делает администратор (токен бота — `#secret/telegram.json`, книга `chats` в class.js сервиса, роли на `/SERVICES/Telegram`).
2. Адресат — только из книги (`contacts`). Нет нужного — администратор добавляет (метод `updates` показывает, кто написал боту `/start`).
3. Текст — коротко: что случилось, где смотреть (WORK-путь), что нужно сделать. Без секретов, персональных данных и сумм, если об этом не просили — Telegram внешний канал.
4. Отправка подтверждается пользователем; не шли повторно одно и то же — лимит 20 сообщений в минуту.
5. Основной канал — лента WORK (`send`): Telegram дублирует важное, а не заменяет запись в ленте.
