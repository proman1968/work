# Оргструктура

1. **Источник.** Текст пользователя или файл (`read` xlsx/csv): колонки *подразделение*, *рабочее место (должность)*, *руководитель*, *сотрудники*. Неясно — покажи, как понял, и уточни.
2. **Точка организации и различие сущностей:**
   - **Организация** — класс типа `$base` в `/ORGANIZATIONS/<Орг>`.
   - **Подразделение (отдел, департамент, лаборатория)** — дочерний класс типа `$structure` (создаётся через `create_class` с обязательной подходящей по смыслу иконкой `icon`, например `carbon:machine-learning-model`, `carbon:chemistry`, `icons:account-balance`, `icons:shopping-cart`, `icons:store`, `icons:assignment-ind`, `lineawesome:shuttle-van-solid`).
   - **Рабочее место (должность, например «Главный бухгалтер», «Менеджер по продажам», «Исследователь»)** — **НЕ класс `$structure`**, а запись в массиве `"#security".ROLES` внутри `class.js` своего подразделения: `{ id: "researcher", label: "Исследователь", USERS: [...], LINKS: [...] }`. Создаётся и настраивается инструментом `assign` с параметрами `place` (латиницей, например `"researcher"` или `"head/accountant"`) и `label` («Исследователь»).
3. **Сверка людей.** Для каждого ФИО найди пользователя (`call path=/USERS method=items` или `access`/`send` с ФИО покажут неоднозначность). Нет пользователя — список «зарегистрировать» пользователю, в роли не назначай.
4. **План** (показать пользователю до изменений при пакетном развёртывании): дерево подразделений, их иконки, рабочие места (`#security.ROLES`), BOSS и сотрудники каждого места, что уже существует (не создавать повторно).
5. **Создание** сверху вниз:
   - Подразделение: `create_class parent=<родитель> id=<имя_snake_case> type=$structure label=<Название> icon=<набор:имя>`;
   - Рабочее место внутри подразделения: `assign path=<подразделение> place=<id_места> label=<Название должности> add=[сотрудники] links=[...]`;
   - Руководитель подразделения: `assign path=<подразделение> role=BOSS add=[руководитель]`.
   Руководитель вышестоящего подразделения видит нижестоящие автоматически (BOSS — scope subtree): не назначай его вниз повторно.
6. **Проверка:** `ls depth=2` точки организации, `read` созданного подразделения.
7. Итог: созданное дерево подразделений и рабочих мест (пути), назначения, кого не нашли, что проверить человеку.
