# Оргструктура

1. **Источник.** Текст пользователя или файл (`read` xlsx/csv): колонки *подразделение*, *родитель*, *руководитель*, *сотрудники*. Неясно — покажи, как понял, и уточни.
2. **Точка организации.** Обычно класс типа `$base` (`read` — контракт). Подразделения — классы типа `$structure` внутри неё и друг в друге.
3. **Сверка людей.** Для каждого ФИО найди пользователя (`call path=/USERS method=items` или `access`/`send` с ФИО покажут неоднозначность). Нет пользователя — список «зарегистрировать» пользователю, в роли не назначай.
4. **План** (показать пользователю до изменений): дерево подразделений, BOSS и USER каждого, что уже существует (не создавать повторно).
5. **Создание** сверху вниз:
   - `create_class parent=<родитель> id=<ИМЯ> type=$structure label=<Название>`;
   - `write <подразделение>/$structure/readme.md` — назначение, задачи, кто отвечает;
   - `assign role=BOSS add=[руководитель]`, `assign role=USER add=[сотрудники]`.
   Руководитель вышестоящего подразделения видит нижестоящие автоматически (BOSS — scope subtree): не назначай его вниз повторно.
6. **Проверка:** `ls depth=3` точки организации, `access` на 1–2 подразделения.
7. Итог: созданное дерево (пути), назначения, кого не нашли, что проверить человеку.
