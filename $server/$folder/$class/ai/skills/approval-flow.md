# Согласование документа

1. **Цепочка.** Из контракта места или от пользователя: кто согласует и в каком порядке (обычно BOSS подразделения, затем вышестоящий). Имена — пользователи с ролью в точке (`call members`).
2. **Запуск:** `send kind=order to=[первый согласующий] due=<срок> includes=[документ] message="На согласование: <что>, <что проверить>. Ответьте done — согласовано, reject — с замечаниями."`. Запомни id.
3. **Ход:** решение согласующего — запись `done` или `reject` с `reply_to=<id>` (`logs` точки).
   - `done` — следующий в цепочке: новый `send kind=order … reply_to=<id предыдущего>`;
   - `reject` — замечания автору, новая версия документа (история файла сохранит прежнюю), согласование заново с этого шага.
4. **Контроль сроков** — по просьбе или `schedule` ежедневно: просроченные шаги — сообщить инициатору; напоминание `send kind=remind` — с его согласия.
5. **Завершение:** последнее `done` — запись `send kind=done` инициатору: «согласовано всеми», список решений (кто, когда, id).
6. Итог: статус, на ком сейчас, история решений.
