# Импорт таблицы

1. **Таблица:** `read_table path=<файл>` — листы, колонки, первые строки, всего строк.
2. **Куда:** класс и тип объектов (`schema`/`read` класса, поля — `METADATA.FIELDS` типа `$oml` и т.п.). Нет подходящего типа или полей — это задача builder, не импорта.
3. **Сопоставление** колонок → полей (`map`), имя объекта (`name_field`). Покажи пользователю таблицу сопоставления и что будет пропущено.
4. **Пробный прогон:** `import_objects … dry_run:true` — ошибки обязательных полей, неизвестные поля, пример объектов. Исправь `map`/данные.
5. **Дубли:** если в классе уже есть объекты — `query` по ключу (код, ИНН); повторы не импортируй, перечисли их пользователю.
6. **Импорт** (с подтверждением): `import_objects …` частями до 1000 строк (`read_table offset/limit` → `rows`).
7. **Проверка:** `query` — число новых объектов совпадает; 2–3 объекта `read` выборочно.
8. Итог: сколько создано, пропущено (почему), где лежат, одна запись в ленте класса о импорте.
