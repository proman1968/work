# Откат файла

1. **Версии:** `history path=<файл>` — снимки (новые первыми, до 50). Нет истории — откатывать нечего; скажи об этом.
2. **Что менялось:** `read` текущей версии и 1–2 подходящих снимков (путь снимка берётся из `history`), сравни; покажи пользователю разницу своими словами и какой снимок предлагаешь.
3. **Выбор снимка:** по времени и содержанию; несколько кандидатов — спроси. Если нужно лишь «посмотреть, как было» — не восстанавливай, дай выдержку.
4. **Откат:** `restore snapshot=<путь снимка>`. Восстановление — обычная запись файла: каждая версия, включая ту, что была до отката, остаётся в истории, так что откат обратим — скажи об этом пользователю.
5. **Проверка:** `read` файла — содержимое совпадает со снимком; `history` показывает новый снимок.
6. **Файла уже нет в дереве** (удалён) — по пути файла `history` ничего не вернёт: сообщи об этом и предложи `escalate` администратору, не подбирай пути вслепую.
7. Итог: какой файл, к какой версии (дата), что изменилось.
