# Поручение

1. **Где.** Точка поручения — подразделение, к которому относится работа (по умолчанию место задачи). Прочитай её контракт (`read` класса): там могут быть правила поручений.
2. **Кому.** Получатели — пользователи с ролью в этой точке (`call members` на классе). Ищи по ФИО; неоднозначно или нет роли — уточни у пользователя (`ask_user`).
3. **Текст.** Кратко: *что сделать*, *какой результат*, *к какому сроку*, *где взять материалы*. Вложения — видимые тебе файлы WORK (`includes`).
4. **Отправка:** `send kind=order to=[…] due=YYYY-MM-DD message=… includes=[…]`. Запомни id из ответа — это номер поручения.
5. **Контроль** (по просьбе или по расписанию `schedule`):
   - `logs path=<точка> from=<дата поручения>`: ответы — записи `done`/`reject` с `reply_to=<id>`;
   - нет ответа, срок прошёл — сообщи пользователю; напоминание — `send kind=remind reply_to=<id> to=[исполнитель]` (с его согласия).
6. **Исполнитель отчитывается:** `send kind=done reply_to=<id> message="что сделано" includes=[результат]` — в той же точке.
7. Итог пользователю: id поручения, кому, срок, что будет проверено и когда.
