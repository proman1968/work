# ai/agents — субагенты

Субагент — отдельный агент со своим контекстом и набором инструментов; основной агент поручает ему подзадачу инструментом `task` (`agent`, `description`, `prompt`) и получает его итоговый отчёт. Независимые поручения выполняются параллельно. Лента субагента хранится внутри карточки вызова (`tools[].items`) и видна в UI.

Файл `имя.md`:

```md
---
name: explore
description: Когда поручать (по этому описанию выбирает основной агент)
tools: readonly            # readonly | * | [ls, read, web_search, mcp_*]
model: /MODELS/…           # необязательно: своя модель
maxTurns: 40               # необязательно
---
Роль и правила субагента (добавляются к общему system).
```

Субагентам недоступны `ask_user`, `todo_write`, `save_skill`, `schedule`, подключение сервисов; инструменты ОС и сети (`os_*`, `net_*`, `shell`) — только при явном перечислении и только у администратора; вложенность — не глубже 2.

| Субагент | Назначение |
|---|---|
| [`explore`](explore.md) | исследование дерева только на чтение, отчёт с путями |
| [`web`](web.md) | исследование в интернете, факты со ссылками |
| [`general`](general.md) | самостоятельная подзадача со всеми инструментами |
| [`analyst`](analyst.md) | отчёты и сводки по объектам, лентам и документам; таблицы xlsx/csv |
| [`secretary`](secretary.md) | входящие, поручения с получателями и сроками, контроль исполнения |
| [`auditor`](auditor.md) | аудит доступа и журнала безопасности — только чтение и рекомендации |
| [`builder`](builder.md) | прикладная модель: типы, поля объектов, роли и зоны, контракты readme |
| [`it-admin`](it-admin.md) | сервер WORK и его локальная сеть: здоровье, службы, устройства (только ADMIN) |
| [`integrator-1c`](integrator-1c.md) | чтение 1С по OData, выгрузка и сверка с объектами WORK |
| [`negotiator`](negotiator.md) | действия представителя на серверах-партнёрах сети WORK |
| [`reviewer`](reviewer.md) | ревью изменений class.js, методов и контрактов — только чтение |
