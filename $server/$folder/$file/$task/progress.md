# Прогресс: $task

## Последние изменения
- Голосовой режим формы задачи (см. form/file readme): методы `voice_config` / `voice_speak` / `voice_transcribe`, реплика `prompt({ voice })` → `body.voice` → `VOICE_NOTE` в system; подтверждения голосом не принимаются. Причина: диалог с агентом освобождает руки, а подтверждение опасных действий требует экрана.
- Карточка задачи в ленте чата: быстрые действия (остановить, ответить вариантом, продолжить); подписки превью и формы снимаются при смене задачи/уходе из DOM. Причина: утечка слушателей приводила к чужим состояниям и дублям.
- `.task` v2: `class.js` (2237 строк: меню, цель facts/side, pre-slot, навыки-pipe, собственные fill/menu) → тонкий API над `sources/modules/agent/session.js`. Лента — `user`/`assistant`(+`tools[]`)/`summary`/`error`; v1 приводится к v2 при открытии.
- Форма задачи переписана: карточки вызовов с diff, подтверждения и вопросы в ленте, вложенные ленты субагентов, план, режимы Авто/Спрашивать/План, панель артефакта.
- `on_save`: новая задача — первая реплика и запуск; повторные сохранения и идущая работа — пропуск.
- Удалены `task.js`, прежние views/rows (`ui/views.js`, `row.js`, `rows.js`, `form.js`, `quiz.js`, `todo.js`, `html.js`, `ribbon.js`).

## Ключевые решения
- Решение: лента — единственный источник правды (контекст модели строится из неё). Причина: стоп, рестарт, откат и продолжение — без отдельного состояния; ответ человека после рестарта применяется к ленте.
- Решение: вопрос/подтверждение — статус карточки вызова (`waiting`/`approval`), не отдельный блок. Причина: ответ адресован конкретному вызову, модель видит его как результат инструмента.
