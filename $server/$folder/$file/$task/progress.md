## В работе
- DuckDuckGo подозрительно пуст даже на здравые запросы — каскад это обходит, но сервис стоит проверить отдельно; Yandex/SearXNG заработают при появлении ключей/инстанса.

## Ключевые решения
- Решение: race сервисов вместо последовательного каскада. Причина: одинаковый контракт `search` у всех трёх, параллель дешевле по времени, ненастроенные проигрывают гонку без спецобработки.
- Решение: перебор вариантов запроса внутри одного web-блока. Причина: переформулировка через меню = новый блок + новый silent-вызов + шум в ленте.
