# Форма задачи (.task) — микрочат агента

## 1. Что это

Представление `form/file` для `.task`: одна шапка (заголовок, статус, кольцо контекста), лента агента, план, композер; справа — доки (вкладка «Контекст» + полезные результаты работы). ODA-компоненты на стилевой модели ODA (роли и токены `styles.js`: `--subtle-*`, `--accent-soft`, `--radius-*`, миксины `card`/`muted`/`chip`) — без сырых цветов.

## 2. Зачем это нужно

Человек видит, что делает агент (текст, рассуждение, действия с результатом и diff), отвечает на вопросы и подтверждает действия прямо в ленте, останавливает, откатывает и продолжает работу; результаты (файлы, отчёты, сводки) собираются в доках; статистика контекста — всегда под рукой.

## 3. Как это работает

- **Шапка одна.** Развёрнутая в чате (`chat-item`) — своя шапка с кнопкой закрытия; chat-item по событию `own-header` прячет свою полосу, `close-view` — сворачивает. В странице `form` (`work-form`) — шапка встраивается в её верхнюю панель (на место `slot[name=top-panel]`), своей нет.
- **Кольцо контекста** (% окна модели) — показ/скрытие доков; точка — появились новые доки, пока панель закрыта.
- **Доки** (`ui/docs.js` `collectDocs`): файлы, записанные/изменённые агентом (write/edit/картинки/навыки), отчёты субагентов, развёрнутые ответы (длинные или со структурой). Новый док при открытой панели выбирается сам. Текстовый док — копировать, скачать, сохранить файлом `.md` в класс задачи.
- **Контекст** (`computeStats`): модель, провайдер, лимит, использование, токены (вход/выход/всего), рассуждение, сообщения, вызовы, даты, разбивка контекста последнего хода (`body.context` от ядра: system, схемы инструментов; диалог — оценка), исходные элементы ленты с JSON и экспорт сессии.
- **Лента**: подряд идущие действия — группа «N действий» (раскрыта, пока идёт работа или нужен человек; свёрнута по завершении). Стрим — `task.delta` → `streams[id]`; строка берёт более длинное из сохранённого и стрима.
- **Композер**: автовысота, Enter/Shift+Enter, Esc — стоп; вложения — «+», вставка, перетаскивание; диктовка (Web Speech API, где есть); меню режима, выбор модели, уровень рассуждения (если модель умеет), отправка/стоп.
- Данные — файл задачи: `changed` → перечитать (одна загрузка в полёте). Своя реплика видна сразу; лента держит низ, пока пользователь не отмотал (кнопка «вниз»).

## 4. Из чего это состоит

| Файл | Компоненты |
|---|---|
| [`file.js`](file.js) | шелл: размещение шапки, лента, план, композер, доки; состояние доков, стрима, групп |
| [`ui/feed.js`](ui/feed.js) | `microchat-feed` (`segmentsOf`), `-user`, `-assistant`, `-steps`, `-think`, `-tool` (статус, аргументы, результат, diff, подтверждение, вопрос, лента субагента), `-field`, `-summary`, `-error`, `-todos` |
| [`ui/panel.js`](ui/panel.js) | `microchat-panel` (композер), `microchat-menu` (выпадающий выбор) |
| [`ui/dock.js`](ui/dock.js) | `microchat-header`, `microchat-dock`, `microchat-context`, `microchat-doc` |
| [`ui/docs.js`](ui/docs.js) | `collectDocs`, `computeStats` (чистые функции) |
| [`ui/util.js`](ui/util.js) | названия/иконки инструментов, форматтеры, `findShell` |

## 5. В каком это состоянии

Работает на ленте v2; проверено скриншотами (`scripts/ui-shot.mjs`, в т.ч. клики `CLICK=x,y`) в странице form и развёрнутым в чате, на живых прогонах (вопрос → ответ кнопкой → продолжение).

## 6. Дальнейшие планы
