# Форма задачи (.task) — микрочат агента

## 1. Что это

Представление `form/file` для `.task`: шапка (заголовок, статус, модель), лента агента, план, панель ввода; справа — панель артефакта. ODA-компоненты на стилевой модели ODA (роли и токены `styles.js`: `--subtle-*`, `--accent-soft`, `--radius-*`, миксины `card`/`muted`/`chip`) — без сырых цветов.

## 2. Зачем это нужно

Человек видит, что делает агент (текст, рассуждение, каждый вызов инструмента с результатом и diff), отвечает на вопросы и подтверждает действия прямо в ленте, останавливает, откатывает и продолжает работу.

## 3. Как это работает

- Данные — файл задачи: `changed` → перечитать (не больше одной загрузки в полёте). Стрим — `task.delta` → `streams[id]` шелла; строка берёт более длинное из сохранённого и стрима. `task.state` — статус.
- Действия ленты вызывают методы шелла (`findShell` из `ui/util.js`): `reply(callId, …)` → `approve`, `revert(item)`, `openArtifact(path)`.
- Своя реплика видна сразу (`optimisticUser`), лента держит низ, пока пользователь не отмотал вверх; Esc — стоп.

## 4. Из чего это состоит

| Файл | Компоненты |
|---|---|
| [`file.js`](file.js) | шелл: шапка, лента, план, панель, артефакт |
| [`ui/feed.js`](ui/feed.js) | `microchat-feed`, `-user`, `-assistant` (рассуждение, markdown, карточки), `-tool` (статус, аргументы, результат, diff, подтверждение, вопрос, вложенная лента субагента), `-field`, `-summary`, `-error`, `-todos` |
| [`ui/panel.js`](ui/panel.js) | `microchat-panel`: режимы Авто/Спрашивать/План, «Продолжить», `work-prompt-bar` (модель, effort, вложения, голос, TTS, контекст) |
| [`ui/dock.js`](ui/dock.js) | `microchat-dock`: предпросмотр файла (html, картинки, markdown, текст) |
| [`ui/util.js`](ui/util.js) | названия/иконки инструментов, форматтеры, `findShell` |
| [`ui/usage.js`](ui/usage.js), [`ui/tts.js`](ui/tts.js) | индикатор контекста, озвучка |

## 5. В каком это состоянии

Работает на ленте v2; проверено скриншотами (`scripts/ui-shot.mjs`) на демо-задачах со всеми видами элементов и на живых прогонах.
