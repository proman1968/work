- Решение: `need=side` без explore/web/logs — только сбор, не work. Причина: thinking → сразу work, изучения не было.
- Решение: `stop` — признак остановки фокуса, не временный флаг. Причина: снятие `stop` прятало кнопку на activation.
- Решение: инварианты формулируются универсально, без триггер-фраз задачи. Причина: правка под конкретный прогон ломает автономное развитие.
