# $task — сессия агента (файл `.task`)

## 1. Что это

Тип файла данных `.task`: одна длительная работа ИИ-агента с человеком. Файл — JSON-лента (версия 2); класс-слой [`class.js`](class.js) — тонкий API над сессией ядра [`sources/modules/agent/session.js`](/sources/modules/agent/readme.md).

## 2. Зачем это нужно

Задача — полноценный артефакт WORK: лежит в классе, где ведётся работа, видна в журнале, переживает рестарт, её можно продолжить, откатить и разобрать. Агент работает от имени и с правами пользователя в классе, где лежит файл.

## 3. Как это работает

1. Создание: чат сохраняет `.task` (`save_file` с `prompt`) → триггер [`on_save`](triggers/on_save/$trigger/class.js) кладёт первую реплику и запускает агента.
2. Реплика человека — `prompt({ prompt, attachments })`; пустая — «Продолжить». Во время вопроса агента текст — ответ, во время подтверждения — отказ с комментарием.
3. Вопросы и подтверждения — `approve({ call, accept, always, content, values })`.
4. `stop()`, `revert({ id })` (лента обрезается с реплики, текст возвращается в поле ввода), `configure({ model, effort, mode })`, `compact()`.
5. Тело: `{ type:'task', version:2, name, title, model, effort, mode, status, items, todos, allowed, waiting? }` — формат элементов в readme ядра. Файл v1 (прежний движок) при открытии приводится к v2: реплики и ответы сохраняются, служебные поля снимаются.

## 4. Из чего это состоит

- [`class.js`](class.js) — методы файла → ядро сессии.
- [`triggers/on_save`](triggers/on_save/$trigger/class.js) — запуск новой задачи.
- [`handlers/pages/form/file`](handlers/pages/form/file/$handler/readme.md) — форма задачи (лента, план, ввод, артефакт).
- [`handlers/preview`](handlers/preview/$handler/preview.js) — карточка: заголовок, статус, последний ответ.
