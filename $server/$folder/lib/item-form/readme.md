# lib/item-form — форма по метаданным WORK

## 1. Что это

`item-form` — `oda-form` по `METADATA.FIELDS` класса WORK; `item-link-input` — контрол ссылочного поля. Прикладное назначение — карточка объекта или статических полей класса, построенная из описания класса.

## 2. Зачем это нужно

Библиотека `oda/` не знает типов WORK. Системный слой подменяет карту контролов и провайдер дочерних полей: тип поля — путь класса (`/BASE/.../CLASS`) означает ссылку на объект этого класса.

## 3. Как это работает

- Поля — `METADATA.FIELDS` класса `$item` (слои `class.js` уже слиты сервером) или явное `fields`.
- Карта — стандартная `CONTROLS` + `item-link-input` для ссылочных типов.
- Дочерние поля ссылочного поля — поля его класса (`classFields(path)`); загружаются только для отрисованных полей раскрытых блоков, поэтому ссылки класса на самого себя не зацикливают форму.
- Значение ссылки — путь объекта; встроенный объект (значение — объект) показывается вложенными полями.

### Контракт для ИИ-агентов

- Импорт: `~/lib//item-form`. Теги: `item-form` (`$item` — класс; `data`, `readonly`, `fields`), `item-link-input` (`value` — путь; выбор — `item-tree` класса `field.type`).
- Экспорт модуля: `isLink(field)`, `classFields(path)`.
