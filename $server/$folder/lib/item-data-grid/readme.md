# lib/item-data-grid — таблица объектов класса

## 1. Что это

`item-data-grid` — `oda-table` с колонками из `METADATA.FIELDS` класса WORK. Прикладное назначение — табличное представление объектов класса.

## 2. Зачем это нужно

Одна модель описания полей даёт и форму (`item-form`), и таблицу: колонки, контролы ячеек и мини-форма строки строятся из метаданных класса.

## 3. Как это работает

- Поле → колонка: `id` → `name`, вложенные `fields` → дерево колонок (`items`), варианты (`items` / `options`) → `options`.
- Контролы ячеек — стандартная карта + `item-link-input` для ссылочных типов; по умолчанию сортировка, фокус, мини-форма строки, ширина по содержимому.
- Строки — `dataSet` (подаёт потребитель).

### Контракт для ИИ-агентов

- Импорт `~/lib//item-data-grid`; тег `item-data-grid`; свойства `$item` (класс), `dataSet`, `editable` + свойства `oda-table`; событие `cell-changed`.

## 4. Из чего это состоит

- `item-data-grid.js` — `item-data-grid`
