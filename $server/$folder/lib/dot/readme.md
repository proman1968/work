# work-dot — персонаж агента

## 1. Что это

Компонент `work-dot`: мягкая «клякса» с глазами и ртом, по которой с одного взгляда видно, что делает агент. Один и тот же персонаж живёт в голосовом режиме задачи (крупный), в шапке задачи и в превью-карточке задачи в ленте чата (маленький).

## 2. Зачем это нужно

Текстовый статус надо читать, персонаж — нет: слушает, слышит вас, думает, говорит, ждёт решения, готово, ошибка, спит. В голосовом режиме он заменяет панель: на ваш голос реагирует вашим цветом и формой, на свою речь — цветом агента.

## 3. Как это работает

- Свойства: `state` (`idle` · `listening` · `hearing` · `thinking` · `speaking` · `waiting` · `done` · `error` · `muted`), `size`, `eyes` (`round` | `sleepy` | `happy`), `accessory` (`none` | `glasses` | `cap`), `color` (цвет агента), `lively` (постоянная анимация).
- Громкость — метод `setLevel(0..1)` (голос человека или речь агента); шаблон он не перерисовывает.
- В DOM состояние отражается атрибутом `mood` (не `state`: у `[state=error]` в `oda/tools/styles/styles.js` есть глобальные правила).
- Анимация только у активных состояний (или `lively`): после последнего кадра цикл останавливается; в списках карточек нет сотен вечных `requestAnimationFrame`. `prefers-reduced-motion` — без колыхания и моргания, только смена цвета.
- Цвета — токены `--dot-*` в `oda/tools/styles/styles.js`: ваш голос — акцент темы, агент — тот же цвет, повёрнутый на 130° по кругу оттенков; светлая/тёмная схема работает сама.
- Внешний вид задаёт место: `ai/config.js` → `dot: { color?, eyes, accessory }` (метод `$task` `dot_look`, значения очищаются на сервере).

## 4. Из чего это состоит

- [`dot.js`](dot.js) — ODA-компонент (SVG, цикл кадров).
- [`dot-math.js`](dot-math.js) — чистые функции: форма тела (`blobPoints`, `smoothPath`), лицо по состоянию (`faceOf`), рот, моргание, `sanitizeLook`, `dotStateOfTask`.

Подключение: `import '/$server/$folder/lib/dot/dot.js'`.

## 5. В каком это состоянии

Работает: голосовой режим, шапка задачи, превью задачи. Проверено тестами `tests/dot-math.test.js`, `tests/ui/voice-ui.html` и скриншотами всех состояний в светлой и тёмной теме.
