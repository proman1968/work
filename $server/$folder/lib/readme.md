# $server/$folder/lib/ — библиотеки компонентов

Многоразовые библиотечные компоненты, доступные каждому элементу через `~/lib/`.

## Структура

- `chat-item/` — карточка файла/сообщения в чате
- `prompt-bar/` — `work-prompt-bar`: composer; модель/effort/TTS/mic — в баре; хост `send` / `stop` и `::model` / `::effort`
- `tree/` — дерево элементов (item-tree); опциональный `hideFiles`
- `node/` — узел дерева (item-node); «?» в дереве открывает контекстный `readme.md` уровня
- `node-explorer/` — навигатор по системе
- `explorer/` — главная страница-исследователь
- `file-viewer/` — просмотрщик файлов
- `icon/` — компонент иконки
- `menu/` — контекстное меню; `hide-files` + «?» на родителе (тот же `item-node`, что дерево)
- `dialogs/` — диалоговые окна
- `pack/` — работа с пакетами файлов
- `security/` — компоненты безопасности
- `tools/` — вспомогательные инструменты
- `email/` — библиотека работы с почтой
- `site-loc/` — helpers локации `#ctx=…` для site / site-navigation

## Использование

Компоненты подключаются через `imports` в handler'ах:
- `~/lib//chat-item` — карточка чата
- `~/lib//tree` — дерево элементов
- `~/lib//node` — узел дерева

Каждая папка содержит `class.js` с ODA-компонентом. `readme.md` на уровне — контекстная документация: в меню handlers файлы (в т.ч. `readme.md`) убираются из списка (`hide-files`, кнопка «?»), в explorer файлы видны.
