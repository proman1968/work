# $server/$folder/ — системный типизатор прикладных компонентов

Корневой типизатор платформы. Содержит определения всех базовых типов, представлений форм, серверных методов и клиентских библиотек. Доступен каждому классу и папке через наследование (`~` — tilde).

## Структура

- `$file/` — тип файлов и подтипы по расширениям (`$ai`, `$data`, `$eml`, `$ics`, `$md`, `$office`, `$prompt`, `$task`, `$txt` и др.)
- `$class/` — тип класс и подтипы (`$class`, `$device`, `$structure`, `ai/`)
- `$handler/` — тип обработчиков (`$task`, `$trigger`)
- `handlers/` — серверные методы (`methods/`) и клиентские страницы/представления (`pages/form/`)
- `lib/` — библиотеки прикладных компонентов (`chat-item`, `tree`, `explorer`, `consultant`, `class-picker`, …)

## Принцип наследования (`~`) и правки

Любой узел в системе собирает слои отсюда через `_collect_tilde()`:
- `~/handlers/pages/form/` — представления-табы формы элемента в `work-form`;
- `~/lib/<name>/` — переиспользуемые UI-компоненты;
- `~/triggers/on_save/` — триггеры сохранения.

Элементы внутри `/$server/$folder/` являются прикладными компонентами: при роли `BOSS` (вне конкретной организации) их можно изменять и удалять штатными инструментами WORK с подтверждением — это меняет поведение для всех наследников в текущей установке.
