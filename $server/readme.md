# $server/ — метапапка корневого класса WORK

Метапапка корневого `$server`. Определяет общую точку входа дерева, глобальные настройки, роли верхнего уровня (`BOSS`) и содержит системный типизатор `$folder/`.

## Два уровня внутри WORK

- **Ядро движка (`sources/`, `oda/`, `run.mjs`, `#system/`)** — программная платформа исполнения (Node.js + UI-фреймворк ODA). Меняется только при разработке самого движка.
- **Системный типизатор (`/$server/$folder/`)** — прикладные компоненты платформы: базовые типы (`$file`, `$class`, `$handler`), представления-табы форм (`handlers/pages/form/*`), методы (`handlers/methods/*`) и библиотеки UI (`lib/*`).

## Модификация прикладных компонентов

Через наследование (`~` — tilde) содержимое `/$server/$folder/` доступно каждому классу в системе. Хотя эти элементы участвуют в работе всей установки, они остаются **прикладными компонентами**: их можно изменять, дополнять или заменять (с подтверждением пользователя с ролью `BOSS`, проверкой последствий и автоматическим сбросом кэша слоёв; при автообновлении пользовательские правки сохраняются).
