WORK Chrome Bridge

Подключает ваш Chrome к агенту WORK по локальному каналу. При подключении всегда включается режим «только просмотр» (readOnly).

Где взять: откройте WORK → ваш аватар внизу левой панели → Подключения → Токен для подключения (это тот же персональный токен wmcp.…, что используется и для MCP).
