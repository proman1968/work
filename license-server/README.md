# WORK License Server (`work.odant.org`)

Служебный пакет лицензионного сервера, платёжного шлюза ЮKassa, омниканальных ботов техподдержки (`MAX`, `Telegram`, `VK`) и лендинга программно-аппаратного комплекса **ПАК WORK** (`https://work.odant.org`).

## Назначение

1. **Лендинг и конфигуратор ПАК WORK (`/`):**
   - Аппаратная база: **AMD Ryzen 495 8085 · 192 ГБ RAM · SSD 4 ТБ**.
   - Предустановленная типовая учётная конфигурация (аналог 1С) + 4 локальные модели ИИ (`Qwen 3 30B`, `Голосовая ASR/TTS`, `Генерация изображений`, `Embedding`).
   - Базовый комплект (`5 000 000 ₽`): включает **вечную лицензию на 5 одновременных активных сессий** и **1-й год поддержки**.
2. **Срочные годовые лицензии на дополнительных пользователей (по уровням SLA):**
   - **Start** — `15 000 ₽ / год` (до 12 обращений/год на место, время реакции до 8 раб. часов).
   - **Business** — `40 000 ₽ / год` (до 48 обращений/год на место, время реакции до 2 часов).
   - **Enterprise** — `100 000 ₽ / год` (безлимит обращений, время реакции до 15 минут 24/7, выделенный инженер).
3. **Интеграция ЮKassa (`/api/orders/checkout`, `/api/payments/yookassa/webhook`):**
   - Автоматический выпуск и продление подписанных сертификатов `Ed25519` (`WORK-LIC-v1`) с привязкой к `HWID` процессора/платы AMD Ryzen и ключу узла `#system/node-key.json`.
4. **Боты техподдержки (`MAX`, `Telegram`, `VK`):**
   - Webhooks `/api/bots/max/webhook`, `/api/bots/telegram/webhook`, `/api/bots/vk/webhook`.
