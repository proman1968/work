# WORK Chrome Bridge — управление настоящим Chrome пользователя

Расширение MV3 подключает ваш браузер Chrome/Edge к агенту WORK напрямую по защищённому локальному WebSocket-каналу `/~chrome` — без запуска отдельных утилит в терминале и без открытия наружу порта удалённой отладки.

## Возможности

- Агент работает в **собственной сгруппированной вкладке** (`WORK`) в вашем окне браузера и никогда не переключается на ваши личные вкладки.
- Использует формат текстовых снимков `[ref]` (совместимый с `browser_*`): `chrome_open`, `chrome_snapshot`, `chrome_click`, `chrome_type`, `chrome_nav`.
- Передача управления человеку (`chrome_handoff`) со скриншотом текущей вкладки: используется для ввода паролей, 2FA, капч и подтверждения оплаты.

## Установка расширения (unpacked)

1. Откройте `chrome://extensions` в Chrome.
2. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
3. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку:
   `sources/modules/chrome-extension`
4. Откройте в WORK ваш профиль (аватар внизу левой панели) → **«Подключения»** → **«Токен для подключения»** → скопируйте токен `wmcp.<uid>.<секрет>` (или готовую строку целиком, показывается один раз).
5. Нажмите на иконку **WORK Chrome Bridge** в панели Chrome → **Настройки** (или **«Открыть WORK»** прямо из настроек), укажите:
   - Адрес сервера WORK (например, `http://localhost:8001` или `http://localhost:8011`);
   - Токен `wmcp.<uid>.<секрет>` (или вставьте готовую JSON-строку целиком в поле токена).
6. Нажмите **Сохранить и подключить** — статус станет зелёным («Подключено к WORK»).

## Модель безопасности

- **По умолчанию включён режим «только просмотр» (`readOnly: true`):** при каждом подключении разрешены только `chrome_status`, `chrome_snapshot` и `chrome_handoff`. Для открытия страниц и кликов агент сначала запрашивает выключение `readOnly` через `chrome_mode` (подтверждается человеком без «разрешить всегда»).
- **Каждое изменяющее действие (`chrome_click`, `chrome_type`, `chrome_nav`) требует подтверждения** (`askEach`, без «разрешить всегда»).
- **Домен-скоуп на задачу и защита от редиректов:** первый переход на домен спрашивает разрешение для текущей задачи; если клик или редирект уводит вкладку на другой домен, агент немедленно останавливается и запрашивает подтверждение.
- **Нет произвольного JS (`eval`) и паролей:** `Runtime.evaluate` разрешён только для чтения `location.href`, `document.title` и `document.readyState`; пароли в `chrome_type` не передаются — используется `chrome_handoff`.
- **Контроль человека:** закрытие вкладки агента или отмена отладки (`chrome.debugger.onDetach`) немедленно останавливает текущее действие и сбрасывает `refs`.
- **Локальный контур и аудит:** WebSocket `/~chrome` доступен только с `localhost`/LAN и только для расширения (`chrome-extension://…` / `edge-extension://…`), авторизация — по `wmcp.` в первом кадре (без cookies). Все действия пишутся в журнал безопасности (`chrome_bridge`) без введённого текста и токенов. В режиме места `private: true` инструменты `chrome_*` вырезаются.
