## 1. Протокол экономии токенов и управления моделями/сессиями

### Доступные модели и их реальная стоимость (на 1 млн токенов)

| Модель | ID | Input | Output | Cache Read | Cache Write | Назначение |
|---|---|---:|---:|---:|---:|---|
| **Gemini 4 Argon** | `opencode/gemini-4-argon` | $2.00 | $10.00 | **$0.10** | **$0.00** | **Основная рабочая модель (`build`/`plan`, `high`)**: в 2 раза дешевле Opus, бесплатная запись кэша ($0 против $5 у Opus) |
| **Claude Haiku 5.5** | `opencode/claude-haiku-5-5` | $0.10 | $0.50 | $0.01 | $0.125 | **Субагенты разведки (`explore`)** и быстрые точечные проверки (<100k контекста) |
| **Flint 40B / Beam Free** | `opencode/flint-40b-free` | $0.00 | $0.00 | $0.00 | $0.00 | Бесплатные вспомогательные задачи |
| **Claude Sonnet 5.5** | `opencode/claude-sonnet-5-5` | $2.00 | $10.00 | $0.20 | $2.50 | Запасная модель для верстки UI (только с новой сессии) |
| **Claude Opus 5.5** | `opencode/claude-opus-5-5` | $4.00 | $20.00 | $0.20 | $5.00 | Только для финального аудита особо сложных узлов (дорогая запись кэша $5!) |

### Правила экономии денег и токенов
1. **Не переключать модель посреди большой сессии:** у каждой модели свой кэш промпта. Смена модели на 100k токенов заставляет заново оплачивать весь входной контекст.
2. **Основную разработку вести на `Gemini 4 Argon` (`high`):** у неё нулевая стоимость записи в кэш (`Cache Write = $0`) и копеечное чтение из кэша (`$0.10 / 1M`), поэтому длинная серия шагов внутри одной сессии обходится в 10–20 раз дешевле, чем на Opus/Sonnet.
3. **Сжимать сессию (`/compact`) или начинать новую на границах крупных этапов** (когда контекст превышает ~120 тыс. токенов или когда переходим от серверного ядра к вёрстке форм). Вся память между сессиями фиксируется в этом файле и `sources/data/progress.md`.
4. **Не читать файлы мелкими кусками и не гонять полный `npm test` после каждой мелкой правки** — запускать только целевой тест текущего этапа (`node --test tests/<файл>.test.js`).
