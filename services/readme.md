# SERVICES — внешние сервисы-коннекторы и MCP-серверы

## Что это

Каталог внешних интеграций, государственных и финансовых справочников РФ, корпоративных коннекторов и MCP-серверов (`/SERVICES`). Каждый провайдер — дочерний класс с метой `$service`.

## Предустановленный набор сервисов (с ориентацией на бизнес в РФ)

### 1. Справочно-финансовые сервисы РФ (работают «из коробки» без ключей)
- **`CBR` («Банк России / ЦБ РФ»)** — официальные курсы валют ЦБ РФ на любую дату (`get_rates`), валютный калькулятор по курсу ЦБ (`convert_currency`) и действующая ключевая ставка Банка России для расчёта пеней по ст. 395 ГК РФ (`get_key_rate`).
- **`DaData` («Контрагенты и банки РФ: ИНН / ЕГРЮЛ / БИК / ФИАС»)** — офлайн-проверка контрольных разрядов ИНН (10/12 цифр), ОГРН/ОГРНИП (13/15 цифр), БИК и ключевания 20-значного расчётного счёта по методике ФНС и ЦБ РФ (`validate_requisites`), поиск банка по БИК (`find_bank`), а при указании бесплатного ключа DaData — автозаполнение карточки контрагента из ЕГРЮЛ/ЕГРИП по ИНН (`find_party`) и нормализация адресов ФИАС/ГАР (`clean_address`).
- **`RuCalendar` («Производственный календарь РФ»)** — проверка любого дня по ТК РФ ст. 112 и постановлениям Правительства РФ о переносах выходных (`check_date`), расчёт количества рабочих дней и нормы часов при 40/36/24-часовой неделе между датами (`workdays_between`), расчёт дедлайнов в рабочих днях РФ (`add_workdays`).

### 2. Корпоративные интеграции РФ
- **`1C` («1С:Предприятие OData»)** — чтение списка справочников, документов и регистров 1С (`list_entities`), выборка и фильтрация объектов по стандартному интерфейсу `/odata/standard.odata` (`query_entities`), поиск контрагента по ИНН (`get_counterparty_by_inn`) и создание объектов/документов в 1С (`create_entity`).
- **`Bitrix24` («Битрикс24 CRM»)** — работа со сделками (`list_deals`), лидами (`list_leads`, `create_lead`) и постановка задач сотрудникам (`create_task`) через стандартный входящий вебхук Битрикс24.
- **`YandexDisk` («Яндекс 360 / Яндекс.Диск»)** — просмотр файлов и папок (`list_files`), получение ссылок на скачивание (`get_download_link`), сохранение отчётов (`upload_text`) и публикация документов (`publish_resource`) через REST API Яндекс.Диска.
- **`Telegram` («Telegram и MAX: Уведомления»)** — отправка уведомлений сотрудникам и отделам в **Telegram** и российский мессенджер **MAX** с автоматическим подхватом ботов из подсистемы «Мессенджеры» (`sources/modules/notify`).

### 3. Веб-поиск и погода
- **`SearXNG` («SearXNG Метапоиск»)** — метапоиск в интернете без API-ключа.
- **`Yandex` («Яндекс.Поиск / Yandex Cloud»)** — официальный поиск через Yandex Cloud Search API v2.
- **`DuckDuckGo` («DuckDuckGo Веб-поиск»)** — поиск и чтение веб-страниц (`fetch_url`).
- **`Weather` («Погода wttr.in»)** — прогноз погоды по городам и координатам России и мира без ключа.

## Подключение MCP-серверов (`mcp`)

Любой класс в `/SERVICES/<Имя>/$service/class.js` с полем `mcp` автоматически работает как MCP-клиент:
- локальный stdio-процесс: `mcp: { command, args, env }`;
- удалённый HTTP-сервер (Streamable HTTP / SSE): `mcp: { url, headers }`.
Токены и пароли хранятся только в `#secret/` (`secret:ФАЙЛ`) и никогда не попадают в открытом виде в `class.js`.
