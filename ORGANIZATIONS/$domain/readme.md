# ORGANIZATIONS — домен организаций (`$domain`)

Контейнер независимых организаций и проектов типа `$base` (например `/ORGANIZATIONS/Маслоторг`).

## Правила

1. Внутри `/ORGANIZATIONS` создаются только организации (`$base`) и группирующие домены (`$domain`).
2. Каждая организация (`$base`) имеет **собственную изолированную БД** (`<Организация>/$base/#system/work.db`). Данные разных организаций полностью изолированы.
3. При создании новой `$base` автоматически разворачивается её домен `MODULES` и подключаются выбранные модули из `/MODULES/<Модуль>` (например `Register`, `Geo`).
4. Внутри `$base` строятся подразделения (`$structure`), в которых настраиваются руководители (`BOSS`), администраторы (`ADMIN`) и рабочие места (`ROLES`) с привязкой сотрудников (`USERS`) и ссылок на учётные классы (`LINKS`: `read` / `write`).
