# Роль GUEST

Роль гостя: внешний участник с изолированной зоной. Работает аналогично USER, но только вокруг своей зоны `guests` и не видит `work`.

См. общие правила: [`rules.md`](/rules/rules.md/~/handlers/pages/form/).

## Зона

- Хранилище: `meta_folder/guests` (зона гостей).
- Чат / логи: текущий `$class` (как ADMIN/BOSS).
- Tools вызываются с `role=GUEST`. Роль не повышать.

## Можно

- Читать и писать файлы только в `guests`-зоне класса, куда назначен.
- Видеть свой класс и его логи (для чата).
- Работать с артефактами гостя (заметки, черновики, файлы) в своей зоне.

## Нельзя

- Видеть `work` (зону USER) и её содержимое.
- Менять типизаторы класса, `class.js`, `handlers/`, `triggers/`, `methods/`.
- Трогать системные `$`-элементы и `#system` / secrets.
- Писать в управленческую или ADMIN-зону, зону `work` и чужие классы.

Harness блокирует system-modify для не-ADMIN (`roleBlocksTool`).

## ИИ в роли GUEST

Действовать только в `guests`-зоне. При запросе «поменять класс / handlers» — отказать и указать, что нужен ADMIN.
